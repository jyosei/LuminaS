# V30 手动畸变坐标合同

此文件由GPT冻结数值设计；V30生产路径与有限范围验收已完成，实际证据见DISTORTION-V30-RESULTS.md。本合同本身不替代运行或摄影质量证据。

`Recipe.distortion` 为有限实数，范围 `[-0.4,0.4]`，缺省0。它是通用手动校正系数，没有镜头型号标定，也不兼容商业镜头配置文件系数。

方向归一原始源尺寸为W×H，坐标使用像素边界域；中心C=(W/2,H/2)，半对角线平方R²=(W²+H²)/4。对校正画布上的点P，t=|P-C|²/R²，回源映射为 C+(P-C)·(1+k·t/(1+t))。正k将边缘采样位置向外移，负k向内移，中心固定，角点t=1时径向比例为1+k/2。使用半对角线而非独立轴归一保证矩形图像中的圆对称；裁剪后不重新设中心。

径向函数f(r)=r·(1+k·r²/(1+r²))，切向特征值至少0.6；径向导数为1+k·t(t+3)/(1+t)²。非负t下，比例的最大值9/8在t=3取得，因此导数至少0.55。整个有限坐标域均保持单调，不因透视映射到画布外而折返。非有限映射点透明；采样前拒绝越界或非法坐标，避免转整型溢出。数值零直接返回输入点，沿用旧路径。

顺序：输出坐标→翻转/校正画布裁剪/角度→逆透视→径向回源→源邻居暗角补偿→alpha加权双线性采样→白平衡/空间/全局影调。`outputToSource` 与渲染器共用映射公式；未来笔刷/仿制需沿用这条链，不能以4K显示像素代替源坐标。

4K准备和即时更新从不可变完整源读取，只计算目标4K像素。准备身份、就绪取色、proxy/last结果与中性float缓存必须携带distortion；烘焙后清零，防止重复扭曲。普通显示LRU不持有完整源。调色预设保留当前畸变；构图复位清零。修正画布尺寸保持源的宽高比与完整尺寸，边界透明，由用户裁剪处理。

空间算子的支持度量当前仍采用校正画布名义原图像素；局部Jacobian、抗混叠、摄影重采样质量、真实镜头网格标定、目标8GB资源尚需验证。S3 tile仍未生产实现；未来ROI必须携带全源尺寸/偏移，并按完整非线性链计算采样范围与halo。
