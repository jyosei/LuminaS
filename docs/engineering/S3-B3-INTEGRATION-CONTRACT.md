# B3–B5 原生接线合同（待实施）

2026-10-16，GPT 架构决定。这里的 Canvas/Window 接口是下一批计划，**不是已经实现的功能**。实际已有接口为 `EditLoader::requestDocument`、`LocalAdjustmentPanel` 及 `local_renderer`。

## 所有权与界面

沿用现有主题、原生控件和面板宽度，在调整区增加“全图基础 / 局部调整”切换。现有全局控件及其对象名保持行为；新页使用 LocalAdjustmentPanel。未完成的渐变、羽化和完整层管理不放占位控件。

- 持久状态只有 EditHistory 中的 DocumentSnapshot。Window 仅保留一个未提交操作的小快照、选层 ID 和工具状态；不复制像素到历史。
- 首次成功预览后，用真实 sourceHash、方向归一尺寸、raw/facts 调用 bindAsset。已有历史 asset.id 必须保留，只有从未创建文档的照片才生成新 ID。不要从屏幕分辨率猜源尺寸。
- 新建层是一条独立命令，九参数保持中性、蒙版为空；自动选择新层、打开覆盖并启用笔刷。一笔仍只产生一条历史命令。
- 显示、工具、覆盖和选择均为临时状态，不写 Recipe。完整源仍仅使用冻结的文档和原始工作帧。

## Canvas 职责

计划增加笔刷模式、覆盖图层 setter，以及 press/move/finish、大小步进和覆盖切换信号。Canvas 只处理 DIP→当前输出的归一坐标；完整原图映射由 GPT 的共享 outputToSource 路径完成。

- 鼠标按下取得画布焦点；仅左键、已有可显示照片、liveAngle=0、工具可用时开始笔画。按下时记录 Alt 是否要求擦除，之后不随 Alt 改变本笔操作。
- 画笔模式与 crop/picker/hand 互斥。模式切换、缩放、几何变化先结束当前笔画；同尺寸的新 RGB 帧到达不能打断当前笔画。
- Space 按下先提交有效笔画，再进入临时小手；松开结束平移，左键还按住时不能自动开始新笔。必须下一次 press 才能继续绘画，防止跨平移连线。
- Esc 取消未提交笔画。窗口失焦、切图/层/工具提交；finish 先关闭内部手势状态再发信号，避免回调重入重复提交。
- `[ ]` 先结束当前笔画，再改变下一笔大小；`O` 只切覆盖。文本/数值输入、IME 不能触发画布快捷键。现有 Window 的 Esc QShortcut 要先路由局部未提交操作，否则它会抢先走旧的全局复位逻辑。
- 普通浏览保持小手与滚轮围绕指针缩放。画笔游标、临时轨迹或边界反馈不等于真实蒙版，不得用它的绘制耗时冒称真实效果速度。

## 笔画和参数事务

Window/事务控制器先提交全局未完成调整，再冻结当前文档、完整几何、层 ID、组成项 UUID、radius/hardness/strength 和 Add/Subtract。使用 BrushSampler 的 radius/8 弧长采样；拖动时仅替换未提交的小快照。

- 每次 UV 由冻结的原尺寸与完整 global recipe 回到源坐标。拒绝无效映射；不能用已经清除几何的 processingRecipe 回源。
- strength=0、空几何等已确定无意义操作不提交；单纯擦除初始全零蒙版不制造命令。其它“有效”判断不能以局部曝光是否为零代替蒙版是否有内容，因为中性层也需要先绘制蒙版。
- 生成蒙版/层版本时防溢出。一个手势内的缓存仍检查真实内容，不能仅靠相同版本号复用不同草稿。
- 拖动期间以同一代 interactive 标签提供反馈；每次输入增加 draft/job。提交或取消时提升代身份，关闭旧结果门禁。沿用 presentedJob 的单调判断，不能倒退到更早的画面。
- 提交时保留当前已细化的 asset facts，仅把事务负责的层改动放进当前文档；不拿旧快照覆盖后续元数据。若基底已发生不相容改变，拒绝覆盖。commitSnapshot 成功后由历史生成单调 revision/localIdentity。
- 局部参数拖动同样有 base/draft/finish/cancel；保留七个未显示字段。一笔/一次参数拖动只一条历史。全局 commit API 继续保留局部层。
- Undo/Redo 后从历史恢复局部页和选层；跨图统一时间线继续保留。比较原图和裁剪模式使用无局部的显示请求，不修改文档本身。

## 覆盖与异步门禁

计划扩展临时 RenderView 的选层/覆盖状态，并把后台计算的覆盖显示作为独立 EditResult 数据交给 Canvas。photo image、直方图、源帧和导出不能烘焙覆盖色。

- 默认中性层也要能显示真实空/非空蒙版；不能依赖 hasActive(local parameters) 才计算覆盖。
- 覆盖计算复用与实际效果相同的 PreparedBrushMask、原图映射和缓存键。显示用量化只影响覆盖显示，不替代 float 蒙版参与 RGB。
- 覆盖图与照片一起受 path/session/revision/localIdentity/geometry/viewEpoch/job 门禁约束；切层/隐藏覆盖/比较时不允许迟到覆盖重新出现。
- 颜色覆盖应由 Canvas 的 UI 颜色呈现，独立于照片显示器 ICC 转换；屏幕图不能再进入编辑链。C4 再扩展覆盖色/黑白查看，不在 B 假装提供完整软打样。
- 分别记录实际 mask/overlay 到达、RGB 计算和原生 framePainted 的时间。后台返回不等于已经上屏。
