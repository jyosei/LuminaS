# UI/UX V40 计划（设计决策记录）

2026-10-15更新：以下为历史阶段记录；最终实现/验证以 UI-UX-V47-ACCEPTANCE.md 为准。桌面打包已依用户要求退出默认验收流程，后续仅明确请求时执行。

状态：部分实现。本文只记录 UI/UX V40 的决策与当前进度，不代表总体目标完成，也不代表最终测试通过。

## 1. 目标与约束
用户诉求：可访问、简单、流畅；随后要求参考 Photoshop / Lightroom / PixCake 的布局。
约束：原生 Qt，不引入 Web 视图；保留既有核心图像算法与色彩决策，本阶段只动界面层。
视觉方向：黑/灰底 + 用户指定的克制紫色焦点色。避免通用圆角卡片堆叠与装饰性动效（无意义位移、弹跳、脉冲）。

## 2. 官方参考的布局结论
- PS 工作区：应用栏/工具/选项/文档区/面板。要点是"工具、选项、内容、面板"分区清晰、可折叠面板。
- LR 修图模块：照片居中为主，调整面板在右，胶片条在底部。要点是"内容为王、参数靠右、导航在底部"。
- PixCake：精修工具 / 画布 / 缩略图区 / 功能区。要点是功能分区命名直白、缩略图常驻。

## 3. 采纳 / 不采纳
采纳：
1. 内容中心：画布最大面积，居中，四周留出中性灰。
2. 参数靠右：调整面板固定在右侧，不再浮层遮挡画面。
3. 底部胶片条：缩略图常驻，用于切换与浏览。
4. 顶部上下文条：模式/文档信息/工具选项集中在一条，避免分散。
5. 紫色仅用于焦点、当前项、可操作高亮；其余为中性灰阶。
6. 分组与折叠：六组调整 + 跨组参数搜索 + 分组标题箭头。
不采纳：PS 的多面板浮动工作区（对单文档修图过重）、装饰性动效、通用圆角卡片式仪表盘布局。

## 7. 验收矩阵
必须包含真实原生截图与交互检查，不能只以绿色测试作为通过依据：
- 真实原生截图：主界面、分组搜索、窄窗口、200% DPI。
- 键盘：Tab 顺序、焦点可见、快捷键与 Esc 行为无冲突。
- 滚动：调整面板滚动、分组折叠展开后的滚动位置。
- 平移：画布平移与缩放不误触调整。
- 分组搜索：跨组匹配、清空后折叠状态恢复。
- 历史：撤销/重做后界面状态一致。
- 加载失败：给出可操作反馈。
- DPI：100% / 150% / 200% 下无裁切、无错位。
