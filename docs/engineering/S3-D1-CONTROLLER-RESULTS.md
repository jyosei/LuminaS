# D1 后台持久化控制器

2026-10-17。控制器已实现；窗口保存/恢复和强杀重启仍待验收，D1 尚未完成。

`ProjectPersistence` 使用 GUI 定时器调度，后台执行 JSON/SQLite、哈希和源检查。停止提交编辑后 2 秒写独立恢复副本；最多一个任务在途、一个显式请求待处理，恢复写合并为最新版本。显式保存优先，未知既有文件保持保护。快照拥有值副本，不向后台传递窗口指针。

恢复写成功不会清除显式项目的 dirty。显式写入旧版本后，新编辑仍为 dirty；epoch 隔离旧会话，editSerial 作废被新编辑取代的打开任务。取消不能撤回已成功提交的文件。失败不自动重试；用户重试或后续编辑可触发下一次恢复写。加载返回完整候选状态、实际文件 SHA 和源检查结果，由窗口决定应用，不自动替换活动文档。
