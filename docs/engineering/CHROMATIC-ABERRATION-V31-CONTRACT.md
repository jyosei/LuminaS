# V31 手动横向色差合同

GPT冻结数值设计；V31生产路径及有限范围实际验收已完成，证据见CHROMATIC-ABERRATION-V31-RESULTS.md。摄影质量、自动校正与紫绿边去色仍未完成。

`Recipe.chromaticAberration` 为红/蓝两个有限数，各±10，单位是方向归一原图角点处的像素位移。绿色为参考。对共同几何映射后的源点P，以方向归一源中心C锚定，各通道读取 C+(P-C)·s，s=1+clamp(delta/R,-.25,.25)，R为原图半对角线长度。普通摄影尺寸下角点位移等于delta；非常小的图限制至25%比例，防止折返。源中心不因裁剪改变；预览按原始尺寸计算相同比例，不把10个预览像素当成10个源像素。

RAW使用SourceFrame.cameraToWork的逆矩阵恢复已白平衡的相机RGB基底，三个通道分别采样后再由原矩阵回到工作Rec.2020。它不回到Bayer马赛克、不重做AHD，也不能恢复前序RGB16感光/黑场裁剪。JPEG在ICC已转入工作域之后使用LCMS生成的线性sRGB参考基底；这是渲染RGB配准，不冒称相机感光通道校正。矩阵必须有限且可逆，∞范数条件数≤10000；激活校正时无效基底报错，不静默换另一基底。零校正精确旁路旧数值路径，不要求无关的相机矩阵可逆。

共同几何flip/crop/angle→perspective→distortion先得到绿色参考源坐标；红/蓝位置随后按源中心缩放。每个邻居先应用源镜头暗角，再投影到对应通道并做alpha加权双线性采样。各分量按各自覆盖率归一，输出alpha取三个覆盖率的最小值，使边界只保留共同有效范围，不将缺失通道补黑或复制边缘。负值与超白不裁剪。工作RGB重组后继续draft WB、空间与全局影调；已烘焙字段清零，防重复校正。

4K即时计算仍从不可变完整源读取，仅计算4K目标。配方、取色就绪、last/proxy/准备和空间缓存均须含色差身份；中性float缓存只能存零值状态。调色预设保留色差，构图复位清零，单项复位只清对应参数，使用现有统一历史。

当前没有自动色差估算、镜头配置文件、紫绿边去色或S3局部保护。摄影边缘纠正、通道基底往返、透明边界、4K/全源位置一致、真实R7/45MP资源、关闭/换图/历史与旧任务门禁均需实际验收后再报告。

未来S3的outputToSource表示绿色参考坐标；红/蓝的采样足迹还需额外计算。tile/ROI必须携带全源尺寸与偏移，并扩大到各通道实际源范围，不能将不同tile自身中心作为光学中心。空间支持与抗混叠的局部Jacobian仍未认证。
