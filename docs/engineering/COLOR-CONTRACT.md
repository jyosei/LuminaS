## 输入与工作域

方向归一后的完整源进入直通 alpha RGBA float32、线性 Rec.2020 D65。工作域保持负值和超白；源 Frame 发布后不可变。原片路径与 SHA-256 是源身份，读取/已提交渲染前后检查完整内容，变化报错。拖杆期间只使用已经验证的不可变缓存，松手重新检查源，避免每帧读盘/hash。完整源解析/4K采样串行，完成后释放完整源，只保留当前4K工作帧和有界缓存；RAW WB精算或几何变化时再从源计算。

JPEG 从完整编码像素读取，EXIF 方向由 QImageReader 归一。独立解析 APP2 ICC，按顺序拼接，拒绝缺片/重复/损坏/超过4MiB；Little CMS 做输入 ICC → 工作域，不先手动去 gamma。无 ICC 明示按 sRGB。非 RGB ICC 拒绝；CMYK/特殊 JPEG 不列为已支持。ICC 标签本身不会被误认为已完成像素转换。

RAW 直接从 CR3 重读，固定 LibRaw 0.22.2、AHD、完整尺寸、厂商有效裁框与方向、gamma=1、no_auto_bright=1、half_size=0、output_color=0、16-bit 相机 RGB、highlight=1。相机 WB 为基础，通过 user_mul 在去马赛克之前修改红/蓝/绿增益；禁用 use_camera_wb 覆盖 user_mul。以最大 WB 增益归一，减少 WB 放大导致的相机通道截断，再在 float 中还原 max/min 增益并应用 LibRaw rgb_cam 矩阵，线性 sRGB → 工作域由 Little CMS 完成。

此桥接保留 float 矩阵产生的负值/超白，优于 S1 已截到 RGB16 sRGB 的显示中间图。相机 RGB16、传感器饱和、黑电平下限与 AHD 内部边界依然存在，**不能称完整无截断 scene-linear 母版或声称恢复传感器已丢失的高光**。原 CR3 始终保留，WB 改动从源重新显影。无相机 WB/非三通道 Bayer 输入明确拒绝，更多机型仍需质量验证。

## 参数公式与顺序

参数是每图独立内存 recipe，范围：曝光 ±5EV，对比度 ±1，高光/阴影/白色/黑色/鲜艳度各±1，饱和度 0–2，暖冷/绿色 ±1EV，校直 ±45°。顺序为源 WB → 几何采样 → JPEG RGB 平衡 → 曝光 → 对比度 → 分区影调 → 鲜艳度/饱和度 → SDR 输出。新JSON键缺省0，旧recipe仍可读取。

- 曝光：RGB × 2^EV。
- 对比度：线性 RGB 以 .18 为支点，(RGB−.18) × 2^contrast + .18。
- 饱和度：Y=.2627R+.6780G+.0593B；Y+(RGB−Y)×saturation。
- 分区影调为LuminaS自己的有界亮度权重模型，不宣称复刻商业算法或高光重建。Y按上述Rec.2020权重计算，用于查表的Y限制在0–4，t=Y/(Y+.18)、d=1−t；增益g=2^(2×shadows×d²+2×highlights×t⁴+blacks×d¹²+whites×t¹²)。4097项float表、线性插值，超过查表范围使用端点增益；实际RGB不截断，乘g保持色度比例。白/黑控制明暗端密度，不是硬剪切白点/黑点；零仍保持零。
- 鲜艳度：C=clamp((maxRGB−minRGB)/max(abs(maxRGB),.18),0,1)，有效饱和倍率=saturation×[1+vibrance×(1−C)]，再沿Y调整色差。低饱和色作用更大，灰色不染色、完全饱和色不继续增加；没有人脸识别或专门肤色保护声明。
- JPEG 暖冷：R×2^warmth、B×2^−warmth；绿色：G×2^tint。它是已渲染 RGB 的基本调节，不冒称物理 RAW WB/开尔文色温。
- RAW 暖冷/绿色修改相机通道 WB。拖动期间通过源相机→工作矩阵的逆变换和相对WB增益，对4K缓存提供快速反馈；这不是重跑AHD的精算等价物。松手从CR3按最终WB重新显影，随后不再次施加RGB增益。

有限基本色调是 CPU 参考算子，不是最终人像曲线/高光重建。非法 recipe 与采样到的 NaN/Inf 拒绝。几何在直通 float 源上读取，插值先预乘线性 alpha、再解预乘；alpha≈0 输出零颜色，防止透明像素污染边缘。

## 曲线与八色段 HSL

顺序扩展为鲜艳度/饱和度 → RGB总曲线 → R/G/B通道曲线 → HSL → SDR输出。V23将点曲线容量扩展为2–64点，端点横坐标0/1、相邻至少1e−10；坐标有限且0–1，导数及外推斜率有限且绝对值≤4096。无显式切线仍使用PCHIP；显式n+2数组携带结点导数及左右域外斜率，供精确预设曲线过渡重放。身份曲线直接旁路。显示和计算共用PCHIP三次Hermite切线；区间内C1连续、单调点无过冲，区间外沿端段割线线性外推，不硬截工作域。映射先作带符号sRGB式编码，再曲线、带符号逆编码；不是先把Rec.2020色域转换成sRGB。活跃通道各32769项float表覆盖线性−1至8，线性插值，范围外使用解析公式。

八色段中心角为0/30/60/120/180/240/270/300°，360°回红；邻段用smoothstep混合，3601项表含循环端点。配方hue/saturation/luminance各±1，对应色相±30°、饱和倍率1+saturation、明度倍率2^luminance。在线性Rec.2020 RGB计算色相与色差；选择权重C=clamp((max−min)/max(abs(max),.18),0,1)，色相偏移、饱和倍率相对1、明度倍率相对1均乘C后应用。灰色旁路、近灰渐弱。旋转色差后围绕原max/min中点重建RGB，再乘明度倍率，保持未截断float，最终SDR编码才裁范围。并非商业工具的感知HSL或专门肤色保护。

曲线与HSL修改不可变4K缓存的渲染结果，不累积修改缓存本身；完整源按同一配方重放。旧JSON缺少curves/hsl时取身份/零，新字段存在但格式或范围错误则拒绝。四通道/八色段分别存储，切换面板通道不新增历史；一手势一条历史，跨图时间线不变。

## 颜色分级与黑白混色

V22：monochromeStrength 为0–1，默认及旧JSON缺省1；关闭黑白保留比例但不生效。共享原色/影调/亮度处理后，部分比例分别执行完整彩色分支（鲜艳度/饱和度、RGB曲线/HSL/分级）和完整黑白分支（按转灰前颜色混色、RGB曲线/HSL/分级），在线性Rec.2020 RGB混合，再执行后续暗角/SDR；alpha不变，不分配两幅整图缓存。0严格等于彩色分支，1保留旧黑白模式效果。预设总强度已按V23接入；黑白比例与总强度为不同控制，见各自结果报告。

### RGB原色风格

Recipe.primaries为三组hue/saturation各±1，对应UI色相±30°和饱和度偏移；旧JSON缺省0，字段存在须三对象/数值类型/有限范围。工作域Rec.2020单位原色Pi的亮度Yi固定；Hi为各原色0/120/240°加30h后的单位HSV色相RGB，Ui=Yi·1+(1+s)·(Hi−Y(Hi)·1)，Di=Ui−Pi。输出RGB'=RGB+ΣDi·(RGBi−Y)，灰阶直接旁路、Δ亮度为零，负值/超白不截工作域。位置在全局曝光/对比之后、分区影调及后续光色之前。该自有风格矩阵与相机/DNG标定无等价声明；真实颜色/质量与资源结果见PRIMARY-V11-RESULTS。

颜色分级为三个独立范围（阴影/中间调/高光），hue为0–360°、saturation为0–1着色强度、luminance为±1EV；共同gradingBlend为0–1、gradingBalance为±1。先从饱和HSV圆得到各范围的RGB方向，减去Rec.2020加权亮度，乘.6×强度，成为亮度为零的着色向量。亮度Y在0–4查4097项表；t=clamp(Y/(Y+.18)+.25×balance,0,1)，spread=.1+.35×blend。S=1−smoothstep((t−(.25−spread))/(2×spread))，H=smoothstep((t−(.75−spread))/(2×spread))，M=max(0,1−S−H)。正balance偏高光、负偏阴影。tint为三范围向量的S/M/H加权和，gain为2^各范围EV的同权重混合；结果=(RGB+max(0,Y)×tint)×gain。单独着色在工作域保持原加权亮度，黑零保持黑零；EV可改变亮度。超过表范围仅使用端权重，真实RGB不剪切。此为自有线性工作域分级，不宣称商业色轮感知效果等价。

黑白模式在基本影调之后、鲜艳度/总饱和度/曲线之前，选择转灰前的颜色。八色段中心和平滑邻段同HSL；monochromeMix为各段±1EV，预计算3601项gain表。近灰选择C与HSL相同，gain'=1+(gain−1)×C；输出RGB=Y×gain'，灰阶不被某个色段随意加亮、负灰保留。关闭模式只旁路计算并保留各段配方；混色控件禁用以免显示无效调节。黑白之后的通道曲线和颜色分级可继续做调色/色调，因此开启黑白也可以得到有意的着色成片。

完整顺序：源WB → 几何/4K采样 → 去雾 → 纹理/清晰度 → RAW交互WB近似或JPEG RGB平衡/曝光/对比 → 分区影调 → 黑白混色或鲜艳度/饱和度 → 总/通道曲线 → HSL → 颜色分级 → SDR。RAW停止交互后源WB已精算，矩阵取恒等而不重复WB。非线性预览与完整源重放仍遵循此前非交换合同。新增字段缺省身份值；存在但类型/范围错误的grading/monochrome与既有数值字段均拒绝，不把字符串静默换成零。

## 几何与两种目标

水平/垂直翻转在裁剪/校直后的归一输出坐标上镜像，再逆映射到方向归一原图；渲染采样和outputToSource使用同一规则。4K基底不提前烘焙翻转，防止重复镜像。比例选项约束后续拖选的源像素宽高比，实际归一裁框写入recipe，比例选项本身不是图像参数；小尺寸输出整数舍入可能使结果比例略有偏差。裁剪工具使用未裁/未翻转画面保持源坐标明确，退出后恢复recipe翻转。单轴镜像后临时校直视觉角度取反，最终仍由源几何精算。

空间质感扩充：texture/clarity各±1，放在源WB/几何采样之后、交互WB近似及全局光色之前。以L=log2(max(Y,0)+.018)建立局部对比基底，纹理dT=clamp(.7×(L−Gsmall(L)),−2,2)，清晰度dC=clamp(1.1×(Gsmall(L)−Glarge(L))×4t(1−t),−2,2)，t=max(Y,0)/(max(Y,0)+.18)。RGB乘2^(texture×dT+clarity×dC)，alpha不改，负RGB/超白仍在float；alpha≈0颜色清零。黑零保持零。纹理/清晰度无AI肤色保护或商业算法等价声明，去雾另见下节。

G为三轮可分离扩展盒滤波近似Gaussian，边界复制；相邻整数半径的归一核按方差混合，从而保持连续sigma。每轴r=floor((sqrt(1+4sigma²)−1)/2)，f=(sigma²−r(r+1))/(2(r+1))，每轮核=(1−f)×box(r)+f×box(r+1)；三轮总方差sigma²。原图参考sigma分别1.5/20×原图长边/3840，再除当前sourcePixelsPerPixel。极端小裁框时support上限取目标长边，避免无限半径/整数溢出。透明区用覆盖率加权的分子/分母分别滤波再相除，不把透明黑当邻域颜色；归一后的原图尺寸与采样尺度为真实元数据，视口/DPI不影响sigma。矩统计合成检查两种采样尺度的有效原图方差一致；不声称非线性预览与全源缩小逐像素相等。

空间基底在4K工作帧上预计算并保留一份不可变几何图+两张float细节图，按24bytes/像素计量。当前4K框架最长边3840：方形3840×3840为14.7456MP、337.5MiB；R7 3840×2560为225MiB；合成3840×2160约189.8MiB。不能只按16:9估算。参数拖动重用该基底，再应用增益及全局光色/SDR，不累计修改原缓存。渲染时key包含输入QImage版本、源尺度/原尺寸、RAW标志与几何recipe；构造基底使用恒等draft矩阵，交互WB矩阵随后应用。背景准备与live共用互斥发布，一次一份，正在渲染的shared快照不会被提前释放。曝光/曲线/HSL/分级等全局调整不重建基底；几何或RAW最终WB精算改变输入图像版本则重建，关闭空间效果清理缓存。初版把空间放在全局之后会让拖动基本参数反复滤波，已在工程阶段调整此顺序；preview/full共同遵循新顺序，没有永久项目格式需迁移。

完整源无缓存路径拥有自己的可变构造阶段基底，唯一拥有者在应用增益时移交QImage，避免再复制一张45MP float图；共享4K基底继续用写时复制保证不可变。临时工作缓存升级LM4KF003，记录sourceScale并校验默认完整几何比例，新增header SHA-256与既有pixel SHA-256，旧/损坏版本重新处理；这不是永久项目格式。LRU按写入时记录的字节数记账，不能用损坏后截断文件的当前大小反扣原预算；截断/元数据损坏/尺度失配已负向验证。资源峰值以实际probe/进程采样为准，不能用理论单缓冲大小宣称8GB机通过。

方法参考[扩展盒滤波的理论论文](https://www.mia.uni-saarland.de/Publications/gwosdek-ssvm11.pdf)与[OpenCV官方滤波概念说明](https://docs.opencv.org/4.x/d4/d13/tutorial_py_filtering.html)。实际滚动和、归一与对比算子独立实现，没有引入OpenCV/GPL实现。

crop 为方向归一完整源坐标中的归一矩形。校直绕裁框中心旋转，保持裁框输出尺寸，外侧透明，不自动扩画布/猜裁切。Canvas 的 DIP/缩放/平移仅用于交互，拖框映射回源归一坐标；重新裁切时展示完整未旋转源几何，可 Esc 取消。

校直滑杆拖动时，画布直接旋转当前4K缓存作即时视觉反馈；松手从完整源按最终几何重新采样，消除拖动反馈的重复插值。这种临时画布变换不会写回源或成为完整输出母版。

全尺寸目标 round(源尺寸×crop)；预览对此有效输出取长边3840，小图原有效尺寸。两者用同一 recipe/源坐标逆变换与双线性采样，完整目标从完整源计算，不放大代理。几何变化时生成当前4K工作缓存；曝光/对比度/饱和度/RGB平衡只修改该缓存，参数存入独立recipe；其线性仿射公式可与插值交换，释放和源计算复用相同合同。当前缩小是双线性参考，细密纹理的抗混叠与正式输出锐化未认证。

新增分区影调/鲜艳度也只修改当前4K缓存；完整目标在完整源几何采样后使用同一算子。非线性算子不与缩小平均交换，不能再要求“完整结果缩小”与“4K预览”逐像素相等；源坐标、参数、平坦色块与变化趋势保持一致。零新增参数保留原仿射快速分支；非零使用4线程融合输入仿射→影调/鲜艳度→LCMS派生显示矩阵/编码表，避免每帧额外150MiB中间图。

## 输出与屏幕边界

### 传统亮度锐化

sharpenAmount为0–2（0关闭）、sharpenRadius为.5–4方向归一原图像素（默认1）、sharpenThreshold为0–.1线性Rec.2020亮度差（默认0）。从几何中性图取Y=.2627R+.6780G+.0593B，以既有三轮扩展盒Gaussian近似求Gσ(Y)，σ=radius/sourcePixelsPerPixel；alpha权重归一，透明RGB不参与邻域。D=Y−Gσ(Y)，软阈值D'=sign(D)×max(abs(D)−threshold,0)。在去雾及纹理/清晰度增益之后，对RGB各加amount×D'，然后全局光色；D固定来自同一中性几何图，不因全局曝光或强度变化重算。

这种加性亮度USM保留通道差，不宣称严格保色相或商业Camera Raw算法等价。它可能放大噪声/产生光晕，没有恢复失焦细节；alpha不变、alpha≈0颜色清零，负RGB/超白保留到最终SDR。阈值是亮度差软阈值，不是蒙版或降噪。半径按原图像素换算，区别于纹理/清晰度按原图长边比例定义的尺度。preview/full分别在真实目标像素上滤波，非线性/重采样不保证逐像素一致；4K预览不是原图100%锐化检查。

基底额外一张float D，R7 3840×2560增加37.5MiB；同时开启纹理/清晰度总基底28bytes/像素（262.5MiB），方形3840²为393.75MiB。强度/阈值复用；半径变更重新构建，不允许错误复用旧半径。仅锐化不分配纹理/清晰度/去雾基底。旧recipe缺字段取上述默认，类型/范围非法拒绝。

参数类别参考[Adobe官方Unsharp Mask说明](https://helpx.adobe.com/photoshop/desktop/effects-filters/smart-filters/sharpen-images-with-unsharp-mask.html)，公式/线性工作域/软阈值/原图尺度为LuminaS自身实现，不使用第三方商业代码。

去雾新增dehaze±1：从中性几何工作帧估计大气光A与透射率。统计/引导系数图长边最多1024，实际RGB始终逐像素在真实4K或完整源目标上计算，不将低清RGB放大。alpha加权采样，透明区域不参加大气光选择；局部暗通道取RGB通道最小值并作源尺度邻域minimum，先从原始暗通道最高0.1%候选中选亮度最高的RGB为A（各通道至少.001）。除A后暗通道初值t0=clamp(1−.95×dark,.1,1)；加权快速引导滤波在缩小统计图计算a/b，使用最终目标完整像素Y/Ay作为guidance插值a/b得到t，截至.1–1。邻域原图参考半径分别7.5/40×原图长边/3840，再除源采样尺度及统计图尺度；边界复制，eps=.001。近似统计与源几何统一，不保证preview/full逐像素相等。

正强度d：td=1+d×(t−1)，输出A+(RGB−A)/td；负强度d：td=1+.6d，输出RGB×td+A×(1−td)，增加雾化。零值旁路，alpha保持，负值/超白不硬剪切；这是大气散射模型的自有参考实现，不是恢复真实深度或商业去雾等价。输入低反差纯色/亮天空与肤色可能不符合暗通道假设，仍需实际质量检查。去雾在空间增益之前应用，纹理/清晰度基底也从同一中性图估计；最后走全局光色与SDR。

去雾基底仅保留a/b两张float小图、A/Ay；方形1024上界约8MiB，不保留45MP稠密透射率。仅开启去雾时不计算/保留纹理与清晰度细节图；组合效果共用一张不可变几何图与同一有界基底。缓存强度变化复用，加入此前缺失的特征时重新构造；完整源独占图移交行为不变。

参考原作者[Dark Channel Prior论文](https://people.csail.mit.edu/kaiming/publications/pami10dehaze.pdf)、[Guided Image Filtering](https://kaiminghe.github.io/publications/eccv10guidedfilter.pdf)和[Fast Guided Filter](https://arxiv.org/abs/1505.00996)；只参考公式/方法，独立C++实现，没有下载或复制第三方MATLAB/GPL代码。线性Rec.2020、透明度权重、限额、负强度雾感与低图统计为本工程取舍；画质/尺度/内存以测试报告为准。

工作 float → Little CMS 相对色度 → encoded sRGB RGBA8，输出带 sRGB ICC。固定SDR快速路径由Little CMS生成工作→线性sRGB矩阵及65536项编码表，融合基本仿射参数并分4块CPU计算，不引入GPL加速插件。65536组含负值/超白/高饱和/alpha的对照与融合参数对照最大误差1个8-bit码值，原Little CMS参考路径仍保留。SDR分支把超目标范围截到可编码范围；工作源及前置调整不截断。工程PNG与屏幕预览共用sRGB目标，无屏幕ICC混入输出。

V36 的 QWidget 画布与胶片条在编码 sRGB 预览后增加独立 SDR 显示转换：通过 Windows GetICMProfileW 查询当前屏幕 ICC，再用 Little CMS 相对色度转换为设备 RGB；无有效配置时明确回退 sRGB。画布转换在后台执行，胶片条仅转换有界小缩略图。显示设备像素不进入 Recipe、直方图或完整源输出；换屏/换配置清除旧设备帧。实际本机读取 sRGB Color Space Profile.icm（3144 字节）；合成非 sRGB 目标及原生画布像素已有数值验证。Windows Advanced Color/HDR、多屏实机和校准屏色卡仍未验证，**不能宣称宽色域/HDR/任意显示器色准已通过**。正式 JPEG/TIFF 输出事务与输出检查 UI 属 S4。

### 传统亮度与色彩降噪

V9只调整统计实现：一次行遍历同时提取Y/Cr/Cb/alpha；移交vector并复用Gaussian scratch；按σ缓存alpha分母供各统计与两种色差使用。三轮核、sigma/eps、归一公式、源尺度与条带支持不变；与原每次重新计算分母的参考最大误差<1e−6。当前历史连接忽略任意滑杆down时的数值框editingFinished，由sliderReleased或显式切图/Undo等结束；强制通知回归与原生结果见DENOISE-V9-RESULTS。

noiseLuminance/noiseChroma各0–1，0旁路。从中性几何图分解Y=.2627R+.6780G+.0593B、Cr=R−Y、Cb=B−Y，分别作自引导局部线性平滑。G为现有alpha加权Gaussian近似：μ=G(P)、v=max(G(P²)−μ²,0)、a=v/(v+eps)、b=μ(1−a)、Q=G(a)P+G(b)，差值D=Q−P。Y采用原图σ2px/eps.0016，Cr/Cb原图σ4px/eps.0025；工作σ除sourcePixelsPerPixel。不同于去雾系数的小图统计，降噪统计读取目标真实像素，不借低清RGB替代4K。

组合先加dy=noiseLuminance×DY、dr=noiseChroma×DCr、db=noiseChroma×DCb：R+=dy+dr、B+=dy+db、G+=dy−(.2627dr+.0593db)/.6780，使单独色彩降噪保持Y。再去雾/纹理清晰度增益/锐化/全局光色/SDR；空间基底仍统一从中性几何图估计，并非逐算子重新估计全部邻域。alpha不变、透明颜色清零，负值/超白不剪工作域。低对比纹理可能被平滑；不宣称恢复细节、AI或商业质量等价。

4K存DY/DCr/DCb至多3张float，强度变化复用；新增此前未估计的降噪通道才重建。4K估计采用512行条带减少任务调度，完整源采用128行条带并原位组合，不保留45MP三张差值图。两次Gaussian的有限support决定halo=6(r+1)，其中r=floor((sqrt(1+4σ²)−1)/2)；完整源保存原始尾部halo行供下一块读取，避免读到已降噪的旧行。条带/整幅及原位/缓存路径有数值对照，最终尺寸、峰值与速度以DENOISE-V8-RESULTS为准。

两种参数均非负有限数值，旧recipe缺省0、错误类型/范围拒绝。初次启用需要构建统计；持续拖动从缓存反馈，不将预热速度冒称第一次响应。模型参考[原作者Guided Image Filtering](https://people.csail.mit.edu/kaiming/eccv10/index.html)，Gaussian权重、线性亮度/色差、物理尺度与条带为本工程取舍，未复制第三方代码。
