# 预设强度 V23 结果报告

范围：V23 预设强度（0–100% 相对强度）实现与验证。本报告仅记录已发生的实际事实。

## 1. 强度语义

- 总预设强度实现为 0–100% 相对强度，基于不可变的 beforeRecipe 与选定的 snapshot 计算。
- 0 = 严格基线；100 = 严格应用预设（applyPreset）。
- 数值参数线性插值；grade/hue 走最短弧；零饱和度的 hue 被忽略。
- BW 有效强度量为连续量。
- WB / crop / angle / flips 保持原样，不参与插值。

## 2. 曲线函数混合

- 曲线点取并集；对并集点的函数值做凸组合、解析导数与外部斜率，得到精确的三次曲线函数混合。
- 是曲线函数层面的混合，不是对输出图像的混合（NOT blend output images）。
- 新增可选的 curveTangents（4 个数组）/ luminanceTangents（n+2）；为空时回退到旧 PCHIP 路径。
- 约束：点数 2..64，点间距 >= 1e-10；坐标有限且落在 0..1；导数与外部斜率绝对值 <= 4096。
- 超限或节点过近时失败且不修改（fail without mutation）。
- LumaHDR 右侧使用加权非负外部斜率。
- 共享 UI 图/渲染器消费显式导数；手动编辑曲线时仅该通道回退为 PCHIP，其余通道保持不变。

## 3. UI 与编辑器行为

- 滑块应用：首次先捕获 base，拖动期间更新 4K 草稿，释放时写入 1 条历史记录。
- 手动改动、选择变化、库变化、Undo/Redo、切换均会使草稿失效。
- Esc 取消草稿；切换照片时提交旧照片的草稿。
- 反复来回移动百分比无漂移。
- 提交的普通配方包含这些字段，可在 JSON / 自定义预设 / 全源中正常工作；不需要完整图像混合缓冲，也不依赖临时窗口即可重放。
