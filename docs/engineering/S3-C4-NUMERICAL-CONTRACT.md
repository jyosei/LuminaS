# C4整体羽化与反相数值合同

后续实际数值与原生证据见S3-C4-CORE-RESULTS.md和S3-C4-UI-RESULTS.md；以下为实现前锁定的合同，不将其自身作为验收证据。

2026-10-16。GPT锁定数值与源映射；本合同不是验收证据，C4控件、覆盖色/黑白诊断和原生检查仍需实现。

## 次序和坐标

1. 在方向归一的原始源像素坐标组合所有组成项，沿用Add `M+(1-M)a`、Subtract `M(1-a)`；组件strength各应用一次。
2. 对组合后的整个场M做源空间平滑；不是先分别羽化组件再组合，也不是在最终4K屏幕图上模糊。
3. 对平滑结果整体反相。最后只在目标像素alpha>1e-8且映射有效时保留覆盖；部分alpha不再乘一次，alpha不参与邻域卷积。
4. mask场由几何在整个源平面定义，不在照片/裁剪边界补零。预览和完整源在相同源位置查询同一场，crop/angle/flip/perspective/distortion仍使用共享映射。

## 羽化核

- `Mask.feather=f`沿用已存储的源像素单位和0..16384格式边界；不改变JSON结构，不将其解释为高斯sigma。
- f=0严格走既有解析覆盖路径，保留位模式基线。
- f>0采用可分离、紧支撑的归一化余弦窗。支持半径R=max(2,f)，源网格中心为(k+.5,l+.5)。单轴权重 `w(d)=1+cos(pi*d/R)`（abs(d)<R），边界/外部为0。双轴乘积加权M，再除以两轴权重总和的乘积，常量0/1保持。
- 0<f<2时，将原解析M与R=2滤波结果按f/2插值，确保趋近0时连续且不丢失原有亚像素几何。f>=2使用完整滤波结果；最后覆盖仅作0..1浮点舍入钳位。
- 全源整数像素中心f=2等价单轴[1,2,1]/4。硬阶跃的已知0/.25/.75/1值作为独立测试，不把两个实现相同就视为足够。

## 实现与资源边界

- 标量参考逐样本直接卷积；生产实现把最多512²个输出查询按原始256×256源网格分组，用九个余弦/正弦加权累积矩逐行回答矩形查询，避免存储支持区域整幅二维中间图。
- 单组扫描行宽和高均不超过33026；行存储随支持半径线性增长，查询列表随输出tile点数增长。不能把“有界内存”冒称“大半径足够快”：极大半径非空场的扫描时间仍需C5实测/优化，格式安全边界不是性能承诺。
- 每行/每256列及组之间检查取消；失败/取消不发布部分tile。透明目标不会给邻居带入alpha，反相空蒙版对有效目标是1、透明目标仍是0。
- scratch指标记录容器payload及本次临时峰值估计，未计容器节点/分配器开销，不能代替D阶段进程树RAM验收。整图覆盖只可存在于现有4K代理缓存；完整源消费者逐tile处理。
