# 图片导出 v1 验收 — 2026-10-15

结论：用户批准的导出v1软件范围已实现并完成本机验收。当前源码/开发版可用，不代表旧桌面包具备此功能；本轮没有打包、创建仓库、发布或实现S3。

## 功能与实现

- 顶部右侧「导出」，Ctrl+Shift+E；非模态黑/灰/紫窗口，左侧目标色彩预览/尺寸/命名摘要，右侧滚动设置、固定底部操作；关闭已入队任务的窗口后串行导出继续。冻结准备中会提示稍候，避免关窗丢失未入队意图。
- 当前/多选/全部保留，默认多选否则当前；开始时重新取得最新配方，冻结源哈希、revision、配方、ICC字节与路径。
- JPEG8位品质1–100默认95；PNG8/16；TIFF RGB/CMYK8/16、ZIP或无压缩。CMYK无有效ICC禁止导出，切换格式/ProPhoto位深有可见说明。
- sRGB/Display P3/Adobe RGB/ProPhoto RGB，RGB ICC导入、系统ICC枚举及CMYK导入；ProPhoto16位。相对色度/感知、黑点补偿，始终嵌入目标ICC；显示器转换仅显示分支。RGB/CMYK均直接由float32线性Rec.2020输出，未经过8位sRGB代理。
- 完整尺寸/长边/短边/适配框/百分比/打印毫米或厘米，比例保持且默认不放大；默认300 PPI，单改PPI不改像素数。
- 原图目录子文件夹或指定目录、原名/前缀序号/后缀、编号或跳过，不提供覆盖；设置记忆，3个内置及自定义预设保存/改名/删除。当前设置与预设名同步，避免显示预设与实际参数不符。
- 常用拍摄信息/版权/无，GPS独立默认关闭；白名单重写方向1、实际尺寸与PPI、输出颜色信息，不复制MakerNote、缩略图或显影指令。CR3基本元数据由LibRaw读取，Canon CMT1补充作者/版权。
- 原图完整源重算→完整编辑→浮点缩放→目标ICC→量化/编码→同目录临时文件→解码检查→源复核→不覆盖的同卷提交；透明边缘合白色且界面明示。失败继续、取消、只重试失败/未完成。
- QSaveFile队列记录、版本/大小校验、未知/损坏记录保护；恢复的旧Pending/Running必须点击重试，不会被新批次顺带启动。不恢复半张计算。
- 成片检查读取真实文件，适屏/真实100%物理像素、小手/滚轮；缺失文件原因直接显示，返回原图时切回编辑并收起导出窗口，配方保持，不重导入成片叠加处理。

## 未验证与边界

- 无真实45MP RAW，45MP为合成JPEG；真实R7约32MP。真实45MP RAW质量/资源仍待样本。
- CMYK使用LCMS测试ICC验证数学及文件结构，没有印厂指定纸张实物打样、校准屏或HDR认证。
- 磁盘满以失败输出设备模拟短写/ENOSPC；未故意耗尽物理磁盘。不可写路径另有实际失败检查。
- 不含完整软打样、纸白/黑墨/超色域、水印、多版本、精确MB限制、输出专用锐化、PSD/图层、项目保存或S3。
- 本机软件验证，不代替干净机器发行验收；未更新任何桌面包、ZIP、安装器或快捷方式。
