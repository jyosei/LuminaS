# 色差与去边色：S2后续验证方向

2026-10-14更新：V31手动横向色差已实现并完成有限范围实际验收，见CHROMATIC-ABERRATION-V31-RESULTS.md。以下保留此前参考与设计记录；自动校正和紫绿边去色仍没有生产实现。

Adobe将横向色差的通道尺寸差异与紫/绿边去色分成不同控制，并提供去边色强度、色相范围与取色器。全局去边色可能影响真实紫色或绿色物体，需要范围保护。这些是功能类别参考，不代表LuminaS采用相同算法。[Adobe Camera Raw官方文档](https://helpx.adobe.com/in/camera-raw/desktop/using/correct-lens-distortions-camera-raw.html)。RawTherapee的镜头/几何工具说明提供红、蓝手动校正滑杆，可作为手动交互参考；本次页面直接打开失败，搜索索引可见这一说明，尚不据此判断其数值实现。[RawPedia项目文档](https://rawpedia.rawtherapee.com/Lens/Geometry)。

GPT的设计判断：不能用整幅HSL去饱和冒充去边色，也不能把工作Rec.2020的RGB通道直接称为相机感光通道。先检查RAW的cameraToWork矩阵及其可逆性/条件数、JPEG输入ICC转换后的通道语义，再确定可验证的手动通道配准基底。必须区分工程通道对齐、摄影边色改善与相机/镜头自动标定。

后续边界：绿色参考位置与共同alpha、红/蓝独立径向采样、方向归一原图像素尺度、完整源中心固定、光学暗角先于源采样、当前crop/angle/perspective/distortion的回源链不重新居中。参数烘焙、就绪取色、空间与普通显示缓存身份需包含色差状态，4K即时更新仍只计算4K目标，完整源重放使用同一语义。

数值验收需有已知分离量的合成边缘、通道基底往返、负值/超白/alpha、源不变、零值精确旁路、裁剪/透视/畸变组合、4K与完整源比例、无重复校正及旧任务门禁。摄影验收需另查真实边缘配准、紫/绿物体保留、肤色与高反差细节；没有明显色差的样片只能验证零值与控制流程，不能证明纠正效果。自动识别与镜头配置文件不放置未实现的复选框。

S3局部蒙版仍未实现；未来保护范围和局部去边色必须明确源坐标、全局参考阶段及同一撤销时间线。当前阶段不以计划文档替代S2色差类别实现。
