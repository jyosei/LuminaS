# 参数曲线与亮度点曲线

2026-10-13，LuminaS。新增阴影/暗调/亮调/高光四个独立参数及三条分界，参数图显示对应分区与平滑曲线，只读；通过下方滑杆调整。点曲线新增“亮度”通道，现有RGB/R/G/B保持独立。参数、分界、点曲线分别支持手势历史、复位、recipe JSON与自定义预设；旧recipe缺省中性。

官方参考：[Adobe Camera Raw影调调整](https://helpx.adobe.com/in_hi/camera-raw/desktop/using/make-color-tonal-adjustments-camera.html)说明四区域参数曲线和分界；[Photoshop混合模式](https://helpx.adobe.com/lt/photoshop/desktop/repair-retouch/adjust-light-tone/blending-mode-descriptions.html)说明独立亮度调整与颜色保留的目的。这里只参考功能与交互，本工程不实现商业算法等价或XMP兼容。

## 模型

参数分界s0/s1/s2在(0,1)且含端点的相邻间距至少.05。四区域中心x分别s0/2、(s0+s1)/2、(s1+s2)/2、(s2+1)/2。中心输出y=x+.45×strength×min(左右中心间距)，strength∈[−1,1]。端点(0,0)/(1,1)固定，共六点走共享PCHIP。相邻输出最少仍保留原间距10%，因此全参数组合单调且[0,1]内不溢出；正控制值抬升该区域中心，负值压低，实际曲线平滑联动其他区间。

操作顺序：原色与基本分区影调之后，先参数曲线、再亮度点曲线，然后黑白/饱和度/鲜艳度、RGB点曲线/HSL与颜色分级。两种新增曲线映射线性Rec.2020亮度Y=.2627R+.6780G+.0593B，曲线轴采用正值sRGB式感知压缩。Y>1e−6时RGB统一乘F(Y)/Y，在此范围保留RGB比例，包括正亮度的负通道。负亮度旁路以保留外域数据；0≤Y<1e−6用smoothstep从中性加法连续过渡到RGB比例增益，避免除零和阈值颜色跳变；黑色可被亮度点曲线抬起。这一近黑分支不宣称严格保持RGB比例。alpha不变。

曲线[0,1]内共享C1 PCHIP。超过感知白点以末段非负割线斜率延伸，不因负斜率反转整个RGB；零末段可保持平顶。此域外延伸不宣称边界C1。没有硬剪源RGB，SDR显示最终沿LCMS编码。每条启用曲线使用32769项线性Y[0,8]查表，域外直接计算；中性参数与点曲线精确旁路，分界变化但四控制全零仍中性。
