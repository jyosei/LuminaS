取消/关闭先令任务失效，发送 Cancel 并给予有界宽限期，再终止无响应 worker；验证 Windows 子进程树退出。只清理由本会话拥有的临时目标，不扫描任意系统目录。Prepare 保持 pre-global 工作帧，不烘焙全局或局部效果。测试须覆盖 open/unpack/process/写出阶段的中断、截断/超长二进制、错误 hash 与不一致元数据，不能只测试正常退出。

主依赖顺序为 A → B → C → D；D2 可以在 A1 通过后安排为独立可靠性支线，但不得与主线修改同一文件。D3 必须等 D2 接入后再做最终进程树资源验收。每个主切片出门前补充对应的原生检查和完整源证据，再进入下一主切片。

### 集成接口与所有权

- `PhotoDocument` 是持久编辑状态，`DocumentSnapshot` 是后台只读快照；`RenderView` 保存临时诊断选择，两者不得混成一个持久配方。名称为计划接口，不是现成 API。
- 快照至少冻结 asset ID/hash、源尺寸/方向与 RAW/ICC facts、完整全局 Recipe、有序局部层、算法版本及 revision。快照持有数据引用直至任务完成，不借用 UI 可变对象。
- 渲染规划新增局部感知的预览与完整源入口，复用现有源处理与显示分支；保留现有只传 Recipe 的调用行为或明确迁移其全部调用点。完整源入口不能读取屏幕设备 RGB、覆盖色或放大后的 4K 结果。
- 存储往返保留已确定的图层/组成项 ID、顺序和参数；重开仅重置历史会话，不重新生成 ID 或更改算法解释。未知格式/算法拒绝无损无法保证的覆盖保存。
- 本方案只新增向独立导出模块传递上述冻结快照与渲染结果的能力；不规定导出格式、质量、面板、队列或文件提交行为，也不等待未提供的导出文档路径。

## 6. 性能与资源

- 性能范围：当前开发机上的 24MP/45MP 合成图 + 本地有权限的真实样本。必须标明：**真实 45MP RAW 与 8GB 设备未覆盖**。
- 暖/冷两类测量分列报告。
- 目标指标（**目标，不是已达成**）：事件到原生绘制 overlay p95 ≤ 33ms；已准备基础上的局部效果 p95 ≤ 100ms。
- 复杂全局准备、RAW 解析、完整源计算**另列**，不用动画或 overlay 假冒效果速度。
- 资源同时报 working set、私有提交、磁盘；父子进程一起统计。
- 默认采用 256px 逻辑 tile 与 256MiB 局部缓存，512px 只作对照。沿用现有 512MiB 显示缓存与 4GiB 临时磁盘上限；它们不能替代进程树 RAM 实测。
- 稳态进程树私有提交 ≤ 1.5GiB、RAW/完整计算峰值 ≤ 2.5GiB 为待测目标，计入源、prepared/spatial/output、mask/halo、父子进程与旧任务同时存活的峰值。超标时先定位并减少重复缓冲与无界并发，不通过降低永久编辑精度或改写目标来宣称通过。
- 新增完整源尺寸或局部层数量压力时，记录具体尺寸、层数、笔触与渐变数量；100轮开关需比较稳定阶段趋势，不能用退出释放后的最小值宣称编辑稳态达标。
