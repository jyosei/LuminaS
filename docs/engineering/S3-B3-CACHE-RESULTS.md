# S3 B3：调度、预览缓存与局部面板组件进展

2026-10-16。B3 仍在实施；本文不宣称主窗口笔刷已经可用。A、GPU 首轮和 B1/B2 结果分别见既有报告。

## 当前实现

- EditLoader 新增 `requestDocument`：先验证源身份与配方，再防御性复制小文档，随请求持有至后台完成。当前图与 live 通道均可调用局部渲染入口；保留原 Recipe 请求行为。已有 localIdentity/viewEpoch 门禁继续判断结果，不把后续修改带入已冻结请求。
- `LocalPreviewCache` 默认保留预算 256 MiB，键为调用者生成的不透明字节串；ready LRU、相同键的 inflight 合并、外部句柄 pin、失败不缓存。条目是独立共享对象；清空后旧任务不能覆盖同键新条目，也不撤销仍被任务持有的值。
- 预算不足、条目过大或可淘汰条目都被 pin 时，结果私有返回但不保留。预算只统计缓存保留的 payload 容量，**不是整个进程内存上限**；不以它替代 D 的进程树压力验证。清空后外部句柄仍有效。
- 基础帧键包含源 hash、当前工作 QImage 身份/尺寸、原始尺寸、实际 X/Y 尺度、RAW/WB/矩阵 facts、全局 pre-local 配方和算法身份。裁后暗角/颗粒不进入基础帧键。
- 蒙版键包含源/工作帧身份、原始几何与翻转、输出尺寸、目标层和真实蒙版内容/版本。局部参数、层强度、名称和参数版本不导致蒙版重建；改变笔画、源或几何会失效。不能只依赖调用者自报版本而忽略内容。
- 基础帧与蒙版仅用于 ≤4K 预览。完整源入口不使用这些缓存，继续逐 tile 重放。当前蒙版缓存仍是每层完整预览 float 覆盖率；C5 需要进一步实现受影响 tile 的精确更新、多个图层下的缓存策略及压力验证。
- 新增 `LocalAdjustmentPanel` 原生组件：层选择/显隐、新建笔刷层意图、笔刷/擦除、覆盖开关、大小/硬度/强度、曝光/饱和度。刷新不产生编辑信号，保留其余七参数，滑杆与数值双向同步。组件已编译并做行为测试，**还没有挂到主窗口或接上画布与历史**。

## 空闲状态性能

`s3-b3-cache-effect-4k.json`：同 B2 合成 3840×2560、两笔各 500 点，包含全局线性、局部合成和 sRGB 转换；不包含原生事件、显示器 ICC 呈现或导入。

|---|---|
| 不缓存，三次 | 444.8067 / 430.3173 / 445.0885 |
| 第一次填充缓存 | 514.1085 |
| 缓存后连续改变局部曝光，三次 | 158.2597 / 183.8513 / 153.6010 |

四次带缓存调用：2 次构建、6 次命中，保留 payload 196,608,000 字节（187.5 MiB），每次均与对应未缓存输出逐像素相同。冷缓存更慢是实际代价，不能只展示命中结果。效果≤100ms目标仍未达到；30/60fps不是硬门槛。
