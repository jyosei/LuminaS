# 预设总强度实施前边界

2026-10-13。V23已接入预设总强度：固定基线参数插值、曲线并集上的显式Hermite切线、普通Recipe提交与完整源重放。结果与验收见PRESET-STRENGTH-V23-RESULTS；下面保留实施前需求作为核查依据。V22的黑白比例仍是独立控制。

预设应用需要保存应用前的不可变 Recipe、选定预设快照、照片身份与版本。强度 0% 必须严格恢复应用前调整，100% 必须严格等于 applyPreset 的现有效果；白平衡、裁剪、校直和翻转仍保持应用前值。强度不能反复对当前结果累乘，否则往返拖动产生漂移。预设编辑、选择另一项、换照片、其他手动调整、Undo/Redo 后，必须明确结束或失效旧强度上下文；改名/删除不能让已捕获快照指向另一项。

曲线可能有不同数量与位置的控制点，不能逐数组索引随意插值，也不能缩减成折线或低分辨率代理。实施前需确定可以表示连续曲线过渡、保留准确端点并支持后续编辑的有界模型，验证不同拓扑、紧邻控制点、非单调曲线、亮度与参数曲线组合。颜色分级色相需定义绕圆周的过渡；黑白使用有效混合比例连续过渡。预设总强度与已实现的黑白比例属于不同控制。

拖动沿当前 4K 浮点缓存与最新请求路径反馈，松手精确提交，整次手势只有一条历史；错误或过期快照不得覆盖新编辑。结果必须可从真正完整源重放，不能只保存预览像素或依赖不可恢复的两张显示图。需量测组合空间算子的首次准备、持续反馈和 45MP 资源，不能因为 30/60 FPS 仅为额外成就而取消这些验证。表示与资源方案确定后再实现 UI，当前没有总强度占位按钮。
