## 产品行为

导入菜单增加打开项目（Ctrl+Shift+O）、保存（Ctrl+S）、另存为（Ctrl+Shift+S）、恢复会话和重试恢复写入。Ctrl+O 继续导入照片。状态栏区分显式已保存、项目未保存、恢复副本已更新、后台存储及错误，标题显示未保存星号。关闭提示保存/放弃/取消；显式保存成功前不退出。

生产默认使用应用数据目录下独立 recovery 目录，后台准备目录。测试可传第三个目录参数隔离存储；既有内存测试显式禁用持久化，避免写用户应用目录。恢复入口由用户选择 JSON 副本，不自动覆盖显式项目。

全组快照读取 EditHistory 的已提交不可变文档，包含顺序、标记和当前照片。200 ms 观察周期不序列化、不读盘、不遍历未变笔迹；发现更改后交给控制器 2 秒去抖。显式保存先结束当前手势，再同步并冻结快照。自动恢复不拆半笔或保存 live 参数草稿。未点击照片也在成功预解析后绑定源身份；待解析/失败项保留路径、错误和选片标记。恢复 JSON 新增可选 pending.mark，旧文件缺省为未标记，非法类型/范围拒绝；SQLite 项目格式不变。

项目加载、源哈希检查、历史重建均在后台，加载期间冻结窗口操作。成功后一次替换文档；失败恢复旧项目操作。缺失/变化/不可读源保留文档和照片项，禁止预解析、渲染及源身份重绑。切换项目取消旧预解析并清空其导入状态，不把旧结果归到新会话。相同源事实绑定保持历史指针，避免产生虚假的持久化编辑循环。
