# C3原生集成合同（待实施，不是验收）

2026-10-16。当前数值/事务已在S3-C3-CORE-RESULTS验证，界面部分尚未实现。继续沿用黑灰紫原生Qt工作区、4K效果代理、源坐标小历史与后台文档调度，不把演示线条当真实效果。

## 控制器与指针

- Canvas保持DIP→输出UV、按下时的Alt、Space/滚轮/失焦/退出行为；不计算源几何或局部像素。可复用已有mask pointer信号，但需明确绘画工具和命中handle，不改变旧笔刷路径。
- Window持一个GradientTransaction，currentPhotoDocument/requestEdit/finish/cancel都纳入该草稿；笔刷/渐变/参数/opacity事务同时只一个。新按下前提交前一拥有者，不能再次引入“提交旧参数时结束刚打开的新手势”的B7问题。
- 点击linear/radial工具后，空白处拖动创建该类型组成项；按下时冻结Add/Sub、strength、完整几何、层和UUID。点击已有handle则beginEdit，而不是追加新组成项；未命中handle可继续创建新组成项。
- 一次按下/拖动/释放只一条命令；Esc取消未提交，离开/切图/切层/切工具/失焦提交，Space先提交再平移，下一次新按下才继续；缩放/几何变化先结束。相同尺寸RGB反馈不能中断正在编辑的手势。
- gradientHandlePoints给源空间点，再经sourceToOutput投影为UV。绘制/命中半径按DIP固定；pan/zoom/DPR沿照片的同一变换，不把4K坐标回写源记录。无有效投影的handle不可命中，源点仍保留。可在画布背景显示超出裁剪边界但仍落在widget范围的handle，不能强制裁成源内点。
- 引导线/椭圆是显示层，不能写进canonical图、胶片条、直方图、预览缓存或导出；其重绘不增加照片/真实蒙版上屏计数。发生几何不匹配或非编辑视图时隐藏handle，避免贴到旧帧。

## 面板

- 保留笔刷、擦除、覆盖、层列表、强度和九参数；增加紧凑渐变选择（线性/径向）与有真实ID的组成项选择/移除。使用现有控件和图标体系，无占位AI/仿制入口。
- 组成项按持久顺序显示其类型与Add/Sub；选择现有渐变后重新显示控制点，可继续编辑，不重新生成ID。选择brush可用于移除，但不要把brush点当gradient handles。
- 组成项移除也必须经不可变文档/完整验证、mask和layer版本推进、一次历史；余下组成项按原顺序重算。不在Widget里持久修改Mask或复制RGBA。
- 新建/结束时同步当前层/组成项ID；初始零长度点击或strength0等未提交操作不可留下虚构的组成项。原生文本输入不触发O、[ ]、Delete层或画布工具快捷键。
- Widget只存展示字段/临时选择，不承载算法；同步host刷新时信号参数必须按值拷贝，避免C2的row/model回调借用。

## 必须补的验收

- 实际鼠标创建线性/径向、拖每种handle、重选回调、改源几何后的贴合、一笔撤销/重做、Esc、Space、滚轮、文本焦点、失焦、切图与旧任务拒绝。
- 组成项Add/Sub的真实输出、移除与撤销，组件/层ID稳定，原配方/源SHA不变。匹配实际渲染文档和paint key再比较照片，不能只看“有一次paint”。
- 至少一轮真实R7 JPEG/CR3原生渐变交互与完整源快照重放；数值核心已有probe不冒充这一步。计时继续分离真实蒙版与照片，控制点动画不冒充速度。
- 主窗口布局/控件可达/键盘，单次必要合成截图本机检查后删除；不要累计变体，也不打包。
