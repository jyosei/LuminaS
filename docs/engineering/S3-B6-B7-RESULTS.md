# S3 B6/B7：真实源重放与原生分离计时

2026-10-16。本批延续 B3 原生窗口，不宣称 S3 C/D 完成。生产 CPU，GPU 仍是独立研究分支；没有推送或打包。

## 实际实现与发现

- 新增 `local_replay_probe`，从明确传入的原图重新读取完整线性工作帧，串行验证 4K 与完整源。独立标量蒙版与局部变换核对固定 17×17 网格，包含 Add/Subtract。原图坐标笔迹冻结后在 identity 和 crop/angle/perspective/distortion/双轴翻转下重放；不把 4K 放大充当完整源。
- 新增 `local_native_probe`，以真实 Window、QTest 鼠标和滑杆驱动局部编辑。来源为 R7 JPEG/CR3；不生成截图或导出图像。新建一个层、曝光、绘画一笔、带蒙版调参、关闭蒙版调参，实际一笔保存 46 个源坐标采样点。
- `EditLoader::requestQueued` 提供后台调度前的 GUI 线程时刻。探针使用固定 128 项台账，以 ready 的真实图像 key 配对 `canonicalFramePainted` / `localMaskPainted`；不拿最新 job 给旧呈现帧计时。后台完成、效果计算、蒙版计算、照片上屏、覆盖上屏分别记录；未交付请求不混入分位数。
- 第一轮原生 JPEG 探针失败：没有结束的局部参数草稿在下一次 brushPressed 内被刷新，`finishLocalEdits` 连同刚打开、尚未归属 BrushTransaction 的画布手势一起关闭，实际只留下一个点。补 `pendingParameterCommitDoesNotEndNewBrushPress`，修复前实际失败在 `canvas->brushGestureActive()`；修复后仅在确有活动笔触事务时关闭画布手势。局部参数先提交、一笔随后独立提交，两次撤销分别移除笔触与参数。

## 重放数值

源：`4X1A0705.JPG` / `4X1A0705.CR3`，方向归一 4640×6960（32.29MP）；真实照片不进入仓库或外部 worker。

| 来源与几何 | 4K尺寸 / 局部计算ms | 完整源尺寸 / 局部计算ms |
|---|---|---|
| R7 JPEG identity | 2560×3840 / 469 | 4640×6960 / 1277 |
| R7 JPEG 组合几何 | 2500×3840 / 585 | 3898×5986 / 1468 |
| R7 CR3 identity | 2560×3840 / 476 | 4640×6960 / 1195 |
| R7 CR3 组合几何 | 2500×3840 / 595 | 3898×5986 / 1571 |
| 合成45MP identity | 3840×2133 / 458 | 9000×5000 / 1875 |

每个输出检查 289 个像素，共 2890 点：mismatch 0、网格最大 RGB 误差 0、alpha 位模式一致，且存在非零蒙版和真实 RGB 变化。该结论是网格抽检，不冒称逐像素完整参考比较；小尺寸逐像素参考由现有 local_renderer/local_mask 单元测试覆盖。每帧 SHA 记录于 JSON，不保留整幅输出图。组合几何沿用同一份源空间笔迹，不因几何改变重新定位笔迹。

三个进程峰值私有提交分别约 1497.11、1496.92、2078.14 MiB；这是独立验证进程，含额外参考底图，不能替代 D 的进程树、100轮及8GB设备资源认证。真实45MP RAW仍无样本，未验证；合成45MP仅证明本次尺寸/数值/内存边界。

## 原生实际计时

每阶段持续约1.44秒、12次输入（120ms间隔），并等待最终提交帧。独立进程；OS文件缓存可能已暖，不能称磁盘冷读。默认实际显示器配置，DPR 1.25。时间范围为 requestQueued 到实际 Qt paintEvent 完成，不包含排队前的人为输入间隔，不是显示器扫描输出延迟。

| 阶段 | JPEG实际照片帧数 / 中位 / p95 ms | CR3实际照片帧数 / 中位 / p95 ms |
|---|---|---|
| 新笔迹＋覆盖 | 4 / 498.19 / 523.35 | 4 / 466.77 / 616.81 |
| 已有蒙版＋参数＋覆盖 | 7 / 374.24 / 394.13 | 7 / 336.48 / 487.51 |
| 已有蒙版＋参数，关闭覆盖 | 9 / 275.04 / 317.07 | 9 / 273.10 / 453.17 |

对应蒙版上屏单独记录：画笔 p95 JPEG 523.35ms、CR3 616.81ms；调参覆盖 p95 383.93/487.52ms。当前覆盖依赖真实后台蒙版交付，没有即时游标轨迹来伪装这些数值。

带覆盖参数更新的效果计算中位约159–162ms，蒙版诊断转换约69ms；不带覆盖效果中位约168ms。排队/交付/呈现也占耗时，不能仅报后台计算代表体感速度。真实照片数据进一步确认性能目标尚未达到：overlay p95≤33ms 和效果 p95≤100ms 均未通过；30/60fps按用户要求不作硬门槛。后续 C5 优先减少重复覆盖转换、整帧拷贝和无效重建，再以本探针复测，不通过改永久精度、降到低于4K或丢失编辑来达标。

初次导入到实际绘制为 JPEG 3528ms / CR3 4743ms；原生探针峰值私有提交约790MiB。这只是本机单次观察，不是全部12张导入或持续稳态认证。

## 检查与证据

- 初版探针构建失败于 Windows min/max 宏，增加 NOMINMAX 后 `s3-b6-probe-reviewed-build.txt` exit0。Qt emit 宏函数名冲突已在构建前审查时修正，增加严格 float32 格式及非有限值拒绝。
- 三次重放实际退出0：`s3-b6-r7-jpeg-replay.json`、`s3-b6-r7-raw-replay.json`、`s3-b6-45mp-replay.json`，总进程时长23.48/25.51/14.61秒（含参考计算、哈希和解码，不代表单次渲染）。
- 失败的原生第一轮保留 `s3-b7-r7-jpeg-native.json`；修复后 `s3-b7-r7-{jpeg,raw}-native-reviewed.json` 均 exit0，10.79/12.73秒。源空间起终点误差均0，原生预览长边3840像素。
- `s3-b7-pending-fixed-build.txt` exit0；相关4/4（5.85秒）。局部窗口新增反例先实际失败、再通过。补 queued 来源/标签、无效请求不入队，以及同步观察者替换请求不被外层覆盖的用例。
- `s3-b6-source-manifest.json`：12张原始样片 SHA 全部不变。
- `s3-b67-final-build.txt` 完整构建 exit0；`s3-b67-full-ctest.txt` **49/50，358.47秒**。唯一失败 atomic_file：100次替换的第77次返回 Windows RenameError/拒绝访问；局部窗口7 passed、文档调度5 passed，其余48个CTest目标均通过。失败详情另存 `s3-b67-atomic-full-failure.txt`，不是局部渲染错误，也不能称完整回归已通过。
- 原子写入专项随后独立重复10轮通过（每轮100次替换），日志 `s3-b67-atomic-repeat.txt`。未改重试预算或实现；原因未定位，不能以这10轮通过宣称已修复。既有8次/20ms无休眠重试合同保留，D保存可靠性继续追踪此项。

所有 JSON/日志保存在忽略的 `build/private-qa`，不纳入公开仓库；本批不产生 PNG/JPEG/TIFF 对照输出。
