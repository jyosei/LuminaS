## 观察边界

采样峰值不是连续峰值。采样间隙内已退出或已孤立的子进程可能漏计；查询失败时总量是已观察部分，`memoryComplete=false` 不可当完整树。working set 相加可能重复计算共享页。磁盘枚举是只读观察，不防同账号恶意路径竞态。进程树强杀/无后代存活结论仍须使用 D2 持有 HANDLE/Job 的专门测试，不能由采样器替代。
