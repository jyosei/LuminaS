# V31 手动横向色差 — 结果报告

本文记录 V31 手动横向色差的实现与实际验证。GPT负责数值设计、算法实现、代码审查及本地验收；worker草稿本身不构成验证证据。

## 实现摘要

- 红/蓝两通道各为有限数、范围 ±10，单位是方向归一原图角点处的像素位移；绿色为参考通道。
- 共同几何映射后的源点 P 以方向归一源中心 C 锚定：各通道读取 `C+(P-C)·s`，`s=1+clamp(delta/R,-.25,.25)`，R 为原图半对角线长度。
- 普通摄影尺寸下角点位移等于 delta；极小图钳制到 ±25% 比例以防折返。源中心不因裁剪改变，预览按原始尺寸计算同一比例。
- RAW 用 `SourceFrame.cameraToWork` 的逆矩阵恢复已白平衡、已去马赛克的相机 RGB 基底，三通道分别重采样后再用原矩阵回到工作 Rec.2020；不回到 Bayer，不重做 AHD。
- JPEG 在输入 ICC 经 LCMS 转入工作域后，使用 LCMS 生成的线性 sRGB 参考基底；这是渲染 RGB 配准，不冒称相机感光通道校正。
- 矩阵须有限且可逆，∞ 范数条件数 ≤ 1e4；激活校正时无效基底报错，不静默换基底。零校正精确旁路旧数值路径，不要求无关相机矩阵可逆。
- 共同几何 flip/crop/angle→perspective→distortion 先得到绿色参考源坐标，红/蓝位置随后按源中心缩放。每个邻居先应用源镜头暗角，再投影到对应通道并做 alpha 加权双线性采样。
- 各分量按各自覆盖率归一，输出 alpha 取三个覆盖率的最小值；边界不补黑、不复制边缘。负值与超白（HDR）不裁剪。
- 已纳入 prepare/clear、last/proxy 工作身份、中性取色就绪、几何与源缓存门禁；4K 目标从未经改动的完整源读取；普通 LRU 不含完整源。
- 调色预设排除色差项并保留物理几何；UI 自旋框 3 位小数、红/蓝滑杆、独立复位、比较、裁剪、共享历史、几何复位保留镜头/曝光/其他精度、导航卡片原生。
