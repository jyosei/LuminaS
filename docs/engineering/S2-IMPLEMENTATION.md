# S2 实施方案：颜色、坐标与基本编辑

2026-10-12。此文保留实施前顺序；用户已授权“开始”，S2已按该顺序实现。随后用户明确要求拖动基本参数实时反馈，并建议仅修改内部4K缓存，源计算时重放参数；已采用当前4K几何缓存、仿射参数融合和RAW WB拖动反馈/释放源精算。实际结果以STATUS.md、S2-RESULTS.md和COLOR-CONTRACT.md为准，本文计划表不作为验收证据。

## 保留的产品约束

C++20/Qt6/CPU参考；当前画面长边3840、小图原尺寸；输入上限45MP，真实近45MP覆盖不阻塞当前R7工作。RAW默认灰暗可接受，后续要正常调曝光/WB/色调，不复刻机内JPEG。原片只读、参数非破坏、每图独立；不以4K代理作为完整计算母版。

## 实施顺序与具体产物

| 顺序 | 主要工作与少量文件 | 过关条件 |
|---|---|---|
| S2a 输入/颜色合同 | src/core/document.h/.cpp，src/color/color_pipeline.h/.cpp，JPEG源读取小接口与RAW全尺寸中间数据接口；按实际ABI固定Little CMS | JPEG保留ICC/方向/尺寸；无ICC明示sRGB；进入float32线性Rec.2020 D65；只做一次gamma/ICC转换；明确RAW中间数据范围 |
| S2b 基本参数与CPU渲染 | src/render/cpu_renderer.h/.cpp；曝光、有限基本色调/饱和度、RAW WB与JPEG RGB暖冷两种语义 | 同一recipe计算4K与完整目标；曝光参考/灰阶/高饱和/负值/超白/NaN策略通过；不从代理放大 |

阶段逐块实现并验证后再扩展，不一次创建全量空目录。LibRaw版本与参考路径保留；Little CMS只引入本阶段需要的核心，先核对实际版本/ABI/构建特性再固定。已有交接候选2.19.1并非未安装就假称可用。

## 数据与渲染边界

Document最小保存asset/path+内容hash、源类型、归一尺寸、色彩/范围描述、独立Recipe、revision/draft/geometry版本和dirty；内存集合保存每图recipe，不为每图驻留完整浮点缓冲。选片/多选/当前图继续分开。

JPEG源读取必须保留原输入ICC及全尺寸/原编码数据；现有只为显示生成的sRGB4K结果不能直接成为编辑源。JPEG按已渲染RGB处理，ICC→工作域一次转换；无ICC按sRGB并标明。不要先手工去gamma再交ICC重复解码。

RAW保留原CR3和源显影recipe。S1 RGB16已经WB、缩放且可能裁切，不把转成float就称为无截断scene-linear母版。S2第一步需要确认全尺寸入站数据合同，并用真实素材验证RAW WB/曝光从源重算和高光边界；发现有界中间图无法保留所需调整空间时先修桥接，不用显示增亮掩盖。普通RGB暖冷不冒称RAW物理白平衡。

工作域float32线性Rec.2020 D65；曝光用可复现EV操作；有限色调/饱和度先锁公式及顺序，不增加通用图层框架。负值/超白在工作域按合同保留，NaN/Inf明确处理；显示分支才按明确SDR合同映射。屏幕变换不进入工程全尺寸输出。

CPU renderer接收不可变SourceFrame+Recipe+目标规格。4K和完整目标使用同一参数/几何定义；在需要全尺寸验证时从源计算，不放大代理。当前4K规则对裁剪后的有效输出应用，若有效图已小于3840，保持其原有效尺寸。

## 坐标、历史与异步

坐标基准是厂商有效画面、方向归一后的源像素；crop/straighten以该坐标表示，视口DIP变换单独计算。原图比较显示当前源显影/默认全局编辑前的结果，几何/显示语义须写明，不以机内JPEG替代RAW原图。

全组用一条有序命令时间线，先只有单图参数/几何命令，为后续组命令保留一致顺序，避免各图历史互相覆盖。滑杆draft变化生成预览，释放提交一条命令；文本框Ctrl+Z留给文本，IME不误触图像快捷键。

现有唯一后台任务扩展到session/committed/draft/job/geometry版本核对，在完成入队与实际展示时拒绝过期结果。后台不写显示中的QImage，不把完整RAW/全图调参放GUI线程。缓存仍不作为本阶段前提，未使用的框架不提前建设。

## 必须实际验证

- 数学/ICC：灰阶、曝光阶梯、不同ICC、高饱和、负/超白/alpha及非法值；透明与预乘约定；防重复gamma。
- 几何：当前R7横图/竖图，裁剪四角、90度方向与校直、不同视口/DPI；对同一源坐标/recipe比较4K与完整目标，而非JPEG压缩像素要求完全相等。
- RAW后期：六张样片逐张调曝光/RAW WB/色调后切回保持独立，降低曝光/改变WB观察高光与细节是否从源正确重算；有界RGB16丢失的数据不能靠后续float“恢复”。没有参考真值时只报告可用性/边界，不编造色准。
- 交互：滑杆合并Undo、文本焦点/负数/IME/Esc、原图比较、快速切图与旧draft结果拒绝。
- 源安全/资源：12原片hash不变；仅一张完整数据驻留；本机记录峰值与冷/暖条件，先复用4线程低内存候选；45MP合成JPEG用于尺寸/内存部分覆盖，真实45MP RAW仍未测但不阻塞R7主线。

S2的全尺寸输出首先是工程像素/诊断文件，不放一个假正式导出按钮。局部画笔/仿制、完整缓存/RAW worker隔离、SQLite保存/恢复、组同步/串行导出及发行仍属于S3–S7。
