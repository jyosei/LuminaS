# 去雾与构图扩充：实际结果

2026-10-13，LuminaS，Qt 6.8.3 / MSVC 2022 / LibRaw 0.22.2 OpenMP 4 PASSIVE / LCMS 2.19.1。生产CPU float32路径；浏览器原型未参与。

## 实现

去雾为±1参数：正值减弱估计雾化，负值增加雾感。暗通道/快速引导滤波在最多1024长边统计图估计大气光和a/b系数，最终RGB计算仍读取每个4K或完整源像素；未以低清RGB放大替代4K。去雾在纹理/清晰度与全局调色前应用。零值旁路，缓存强度调节复用统计基底，完整源按recipe重放。模型、透明度和负值/超白边界见COLOR-CONTRACT。

构图新增水平/垂直翻转与自由、原图、1:1、4:3、3:2、16:9拖选比例。比例是当前工具约束，实际裁框写入recipe；选择比例不会自行修改已有裁框或新增历史。镜像应用于裁剪/校直后的输出坐标，源坐标逆映射同步处理。裁剪工具显示未裁未翻转的源画面，退出保留已设翻转。单轴镜像时校直即时旋转方向反转，防止拖动方向与最终计算相反。

“复位构图”一条命令清除裁剪、校直和两种翻转，保留调色；可以整体撤销。调用后退出比较/裁剪工具，回到正常编辑。
