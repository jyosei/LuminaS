# 紫绿边去色 V32

这是手动去色，区别于 V31 的横向通道配准。输入为几何校正和白平衡之后、全局影调之前的不可变 straight linear Rec.2020。候选色相用工作 RGB 描述；紫/绿强度 0–1、中心色相 0–360°、半宽 5–90°、原图名义半径 1–20 像素。七字段严格 JSON，旧配方缺字段保持默认禁用；非法对象原子拒绝。全局预设包含去色，色相按最短圆弧插值；几何复位保留去色。

四对相反方向邻点为边缘证据：两端接近中性且具有亮度对比才抑制候选色度。处理为 RGB=Y+(RGB-Y)*(1-strength*evidence)，Y 权重 .2627/.678/.0593；重叠紫/绿范围取最大抑制量，避免重复去色。保持 alpha、负值和 HDR，不写源帧。零强度走原有渲染路径。

先渲染几何/WB 前缀，再去色，再清除已烘焙几何/WB，应用其他空间及影调操作。RAW 前缀使用实际 draftBalance；新帧归一 draftBalance 避免重复 WB。PointColor 临时范围视图在末段应用，不进入去色缓存。

SpatialCache 内附单个 DefringeCache，最多缓存长边 3840 的 before/after 两张 float 图，未持有完整源。缓存键包含输入 QImage key、几何/翻转/WB 前缀、原尺寸、RAW 标记、cameraToWork、draftBalance、实际 X/Y 支持尺度及目标边长；处理结果额外包含七参数。重任务在 mutex 外计算，generation 防止迟到任务覆盖新缓存。后续影调变化复用结果，范围/强度变化复用 before，源/几何/WB 变化重新准备。

核心与管线组合测试已实际 10 passed（241ms），JSON 7 passed（6ms）；合成 3840×2560 111ms。这不是完整交互耗时或摄影质量认证。合成/RAW/JPEG窗口各3通过，完整CTest16/16通过（430.45秒），结果单独记录。

待验收：真实紫绿边、细彩色物体误去色、晕边和镜头画质；名义半径尚无局部投影 Jacobian 校正。真实细彩色线横跨中性高反差边缘可能与色散相同，不能承诺自动区分。未提供自动镜头标定、模型或 S3 工具。
