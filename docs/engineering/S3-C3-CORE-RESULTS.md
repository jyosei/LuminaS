## 锁定的数值规则

- 全部点/半径仍在方向归一原图的像素边界坐标中；画布UV经冻结的完整 `outputToSource` 回源，不用4K尺寸代替原尺寸。
- 线性渐变 `d=end-start`，`t=dot(p-start,d)/dot(d,d)`，覆盖率 `clamp(t,0,1)`；起始线0、终止线1，外侧半平面保持0/1。退化/非有限端点仍按现有模型拒绝。
- 径向渐变先逆旋转到椭圆源局部轴：`x=(cosθ*dx+sinθ*dy)/rx`、`y=(-sinθ*dx+cosθ*dy)/ry`，`ρ=hypot(x,y)`。ρ≥1为0，中心1，内部为 `(1-ρ)^2*(1+2ρ)`；即完全软笔头的同一平滑三次剖面。角度正向遵循图像y轴向下的源坐标。
- 每个组成项再乘自己的strength一次；与笔刷按原始顺序 Add `M+(1-M)*a` / Subtract `M*(1-a)`。alpha≤1e-8无覆盖，部分alpha不重复乘；覆盖色不进图像计算。整体羽化/反相仍等待C4并明确报不支持。
- 保留旧类名BrushMaskReference/PreparedBrushMask兼容调用者：笔刷仍用原KD最近笔头路径；线性为解析平面，径向使用预计算角度及保守旋转椭圆AABB。线性支持半平面，不用有限笔刷边框误裁；tile256/512、四个有限worker、scratch界限、取消/失败不发布部分输出规则不变。

## 控制点与事务接口

- `sourceToOutput` 仅用于控件呈现，反解既有映射：先在全局单调的径向warp中用有限括区间二分，再逆homography、crop/rotation/flips。无法反解/无效分支不改输出参数，不引入像素颜色重采样。默认80轮上限，根精度由浮点收敛提前结束。
- 线性handles顺序：start、end、中点整体平移；径向：中心、X半径、Y半径、旋转（1.25倍X轴）。它们返回原图源点，后续画布只能做UV/DIP显示/命中，不重写图像算法。
- 创建径向时从按下中心拖到边界先形成圆；随后X/Y及旋转handles可编辑椭圆。半径拖动沿冻结轴投影，最小1源像素；旋转以源局部atan2确定。已有小于1像素半径或大角度的合法记录在无移动点击时不会被暗改。
- GradientTransaction冻结文档、完整几何、层/组成项ID、强度/增减、按下源点与原几何；仅生成小快照。线性按最终端点而非鼠标事件密度记录；一次创建/一次控制点拖动只一条后续历史命令。静止和回基底不重复换快照或制造命令；初始零长度点击、strength0、空蒙版首条Subtract不提交。失败输入保持上一份有效草稿。
- finish始终结束事务；基底/资产/hash/几何/层发生冲突时拒绝覆盖，允许元数据facts细化并从当前文档保留。Esc由后续控制器调用cancel；源维度不从屏幕猜。已有BrushTransaction行为不改。
