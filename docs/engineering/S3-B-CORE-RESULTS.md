# S3 B：蒙版与线性合成核心进展

2026-10-16。本页记录 B1/B2 核心进展，**不代表 B 笔刷闭环或 S3 已完成**。生产画布尚未接入局部编辑；GPU 仍仅为首轮独立实验，生产使用 CPU。

## 实现

- `local_reference`：原图坐标弧长采样、笔头最大覆盖、按序补减、局部九参数线性像素参考；常量与容差见 `S3-B-NUMERICAL-CONTRACT.md`。
- `local_mask`：每笔二维最近邻索引；256 tile，512 对照，当前点运算 halo=0。每 tile 扫描真实映射点形成源范围，不以四角近似非线性回源。
- 预览蒙版最多四个后台线程，线程独占 scratch，写不重叠的目标片段，所有任务结束后才发布。失败/取消保持调用者原结果。完整源走逐 tile 接口，不分配完整源坐标图或覆盖率图。
- `local_renderer`：独立的预览线性、预览 sRGB 与完整源线性入口。顺序为既有全局处理（暂去掉裁后暗角/颗粒）→局部层自下而上→裁后暗角/颗粒→既有 sRGB 分支。完整源入口返回线性 Rec.2020，供后续独立导出接线使用；尚未接导出队列。
- 无生效局部层调用原渲染入口；完整源入口核对原始尺寸、像素尺度、源 SHA、RAW 标记与 RAW 白平衡。缩小缓存不能作为完整源输入。准备后的预览只允许使用完整全局配方或清除已准备几何的对应配方；蒙版始终用文档原始几何及源尺寸。
- 现有点颜色/锐化诊断继续显示其全局阶段，不叠加局部效果；诊断状态仍不持久化。

## 性能口径

本机合成 3840×2560 float32 基础帧，原坐标 6000×4000，2 笔、各 500 点，半径 120、硬度 .6、强度 .8。不读取私人照片，不编码文件，不计原生绘制。不能据此推断真实 R7 导入速度或任意复杂配方耗时。

| 路径 | 五次蒙版墙钟耗时（ms） | 报告 |
|---|---|---|
| 最初串行分配 | 696 / 685 / 678 / 682 / 686 | s3-b2-mask-4k.json |
| 串行复用 scratch | 524 / 525 / 526 / 534 / 527 | s3-b2-mask-4k-scratch.json |
| 四线程，首次验证 | 184 / 173 / 186 / 181 / 175 | s3-b2-mask-4k-parallel.json |
| 四线程，新增 RGB 探针后 | 186 / 175 / 163 / 167 / 170 | s3-b2-mask-and-effect-4k.json |

- 索引 payload 16,176 字节；150 tiles、4 workers，单 worker scratch 与 tile 向量容量合计最大 2,686,960 字节。上述为容器数据容量估计，**不是进程内存实测**。
- 预览蒙版输出 39,321,600 字节；失败保旧意味着计算时新旧输出可能同时存在，不能以该数声称总峰值内存。完整源合成不使用这个全预览蒙版接口。
- 覆盖像素 422,396；200 个单点对照中 29 个非零，逐位差异 0。sumCoverage 的末位双精度差异来自全图行序与旧 tile 序的加总顺序，不是蒙版 float 像素变化。
- 单独的真实 RGB 计算路径（合成数据）：全局线性处理＋局部层＋sRGB，无缓存，三次 437.3856 / 445.2738 / 452.6838 ms。四次输出 SHA256 一致：`3c77b1f93c7c1d7f98bf3f65028cf141a20dcf920cb3b5ab7344c838196e808d`。
- mappingAccumulatedMs / samplingAccumulatedMs 是各线程耗时之和，不是墙钟时间；不得与完整 RGB 耗时混称。未测 overlay/native 事件延迟。效果≤100ms目标尚未达到；30/60fps不是硬通过指标。
