# LuminaS GPU 加速实验计划

2026-10-15。状态：**首轮实验已关闭，结论为"继续研究"**。G0 已完成实际设备与能力记录并采集受限 CPU 基线；G1 仅完成曝光／RGB 平衡／对比度／饱和度的基础融合（曲线／HSL 与分步对照未实施）；G2 仅隔离验证 native/4K 基础路径且限 fixed sRGB，计时端点有限；G3／G4／G5 未实施、无外部验证。常驻 4K 路径有潜力，CPU↔GPU 全往返暂不迁移，生产默认路径不变。实际数值、命令与失败见 [首轮实验结果](GPU-EXPERIMENT-ROUND1-RESULTS.md)；该文不是"G0–G5 全部完成"，也不构成 GPU 性能或兼容性验收。

## 1. 目标与边界

验证 GPU 能否明显改善 LuminaS 的交互延迟和重型图像处理耗时，同时兼顾 AMD、NVIDIA 与资源有限的核显。

- 作为有空时推进的独立实验，不作为 S3、导出或发布的前置条件。
- 首选 **Qt QRhi＋Direct3D 11**，保留现有 CPU 实现作为正确性参考和回退路径。
- 首轮不迁移 RAW 解包／AHD、任意输入 ICC、文件编解码或项目存储，不改变独立导出方案。
- 不重写整个界面；GPU 工作集中在图像处理和画布呈现。
- 实验默认关闭，不改变现有产品路径，不生成桌面包、ZIP、安装器或快捷方式。

## 2. 分阶段实验

| 阶段 | 实验内容 | 通过后再推进的条件 |
|---|---|---|
| G0 基线与能力检查 | 记录实际 GPU、驱动、计算与浮点格式支持；重测当前 CPU 热点；检查 Qt Shader Tools 等构建依赖 | 有可复现基线，明确设备能力和缺项 |
| G1 基础调色 | 使用相同浮点工作图，实现曝光、RGB 平衡、饱和度，再接曲线与 HSL；比较分步和融合处理 | CPU／GPU 数值对照通过，计入传输后仍有收益 |
| G2 常驻预览 | 工作图保留在 GPU，连续修改参数，仅更新参数和必要数据；用独立实验画布验证呈现 | 实际显示延迟改善，连续拖动稳定，无逐帧整图往返 |
| G3 蒙版与局部合成 | 验证笔刷覆盖、渐变、局部曝光合成及受影响区域更新；使用合成记录，不等待 S3 全部完成 | 与 S3 覆盖率、坐标、历史和版本合同一致 |
| G4 空间处理 | 先做锐化所需的模糊，再验证纹理／清晰度；收益明确后再接传统降噪 | 保持现有半径、边界、alpha 与算法语义，完整处理耗时降低 |
| G5 跨设备总结 | 对照 AMD 核显、AMD 独显和 NVIDIA 独显，检查稳定性与资源 | 给出适用设备、获益场景、回退条件及是否值得正式接入的结论 |

每阶段都可以独立停止。若收益不足，保留结果和原因，不为了完成实验继续扩张实现。

## 3. 实现约束

- 使用独立实验程序和默认关闭的构建选项；共享必要的 CPU 算子，不改生产默认后端。
- 输入为不可变浮点工作图、冻结参数和可选蒙版记录；输出实验图像及性能、误差报告，不修改公开项目格式。
- 初始使用 float32，不以改成 float16 或裁掉负值／高光换取速度。
- 连续算子尽量留在 GPU；分别记录上传、计算、同步、读回和实际呈现耗时。
- QRhi 资源由同一所属线程和实例管理，不能假设不同实例之间可直接共享纹理。
- 任意 ICC 转换先沿用 Little CMS；如需 GPU 显示转换，作为独立正确性子实验验证，不能直接跳过。
- 现有空间滤波已采用滑动窗口等优化，GPU 实现不得退化为大半径逐邻域的高复杂度循环。
- 文档、历史和永久编辑数据不依赖 GPU 句柄；设备丢失、分配失败或能力不足时保留 CPU 可用路径。

## 4. 测量、验收与停止条件

### 样本与方法

- 使用小型合成图、3840 长边预览、24MP／45MP 合成图，以及有权限的本地真实样本。
- 覆盖无效果、极端参数、负值／超白、透明边缘、几何变化、跨块边界和连续参数更新。
- 首次初始化单列；稳定路径预热后至少测量 100 次，记录中位数和 p95。
- CPU 与 GPU 使用相同输入、尺寸、算法和质量；同时报告纯计算与端到端结果。
- 分别记录独显显存、核显共享内存、进程私有提交和在途缓冲。

### 初始判定标准

- 正确性必须先通过。初始对照目标为 RGB 误差满足 `绝对误差 ≤ 1e-5 + 1e-4×|参考值|`，alpha 误差≤`1e-6`，蒙版覆盖率误差≤`1e-5`；另检查显示色差与边缘图像。
- CPU／GPU 不要求浮点哈希逐位一致。超出容差时定位原因，不为通过测试而直接放宽标准。
- 重型场景争取端到端耗时降低至少 50%；交互场景优先检查是否达到实际反馈目标。
- 若代表场景端到端收益不足 20%，或内存、功耗、稳定性明显恶化，暂停该路径并记录原因。
- 没有 NVIDIA 实机结果时，只报告已测 AMD 结果，不宣称已完成 A／N 卡兼容认证。

最终结论按场景划分为“建议正式接入”“仅部分设备启用”“继续研究”或“暂不迁移”，不要求所有算子统一使用 GPU。
