# 局部编辑设计：图层、蒙版、笔刷与局部调整（设计与待实施）

2026-10-15。本文只整理已经确认的产品与架构决策，用于后续实现；**本轮不实施任何产品功能**。本文描述的是设计与待实施内容，不代表任何功能已经可用，也不构成验收结论。测试与实现计划见 [S3-LOCAL-EDITING-PLAN.md](S3-LOCAL-EDITING-PLAN.md)。

范围边界：核心图像算法、数值与颜色科学、模型开发与架构决策仍归 GPT；本文不自行设计算子，只记录已确认的公式与顺序。具体软笔头函数、羽化核截断与数值容差由 GPT 在相应核心切片写 CPU 参考时锁定，不由文档工作器发明。

## 1. 产品目标与已确认决策

- 摄影精修优先（不是绘画/合成工具），鼠标优先，交互与视觉沿用当前 V48 UI 基线与黑灰紫配色。
- 编辑面板按“全图 / 局部”分页：全图页保持现有全局调整；局部页包含层列表、蒙版工具与参数区；画布上方为笔刷属性条。
- 不引入多图合成、像素绘画、分组/复杂混合、仿制/自动修复、AI、颜色范围/亮度范围选区、压感验收、参数批量同步。
- 曲线、HSL、颜色分级、细节（纹理/清晰度/去雾/锐化/降噪）本轮仍为全局参数；局部侧只有本文列出的九参数与蒙版。
- 局部调整层同时拥有参数与蒙版：一个层 = 一组九参数 + 一个蒙版。
- 局部层支持命名、显隐、强度（opacity）、复制、删除、排序；全图基础固定在最底部，不参与局部排序。
- 局部九参数：曝光、对比、高光、阴影、白色、黑色、暖冷、色调、饱和度。取值范围沿现有全局对应控件，默认值为“无效果”。暖冷/色调仅作用于工作 RGB，**不是** RAW 物理白平衡，也不回到相机基底。
- 本轮不含：多图合成、像素绘画、层分组与复杂混合模式、仿制/自动修复、AI 相关能力、颜色/亮度范围选区、压感验收、参数批量同步。

## 3. 操作规则

### 3.1 蒙版创建与组成项

- 三种创建方式：笔刷、线性渐变、径向渐变。
- 同一层可以按顺序存在多个组成项，后续组成项按顺序对已有蒙版做增加或减去。
- 渐变控制点可以再次回调（重开层后继续编辑该渐变）。
- 组成项可以删除；删除后蒙版按剩余组成项顺序重算。
- 整层支持：整体反相、可回调的羽化、覆盖色显示、黑白蒙版查看。
- 新建笔刷层时蒙版为空并自动打开覆盖显示，方便看到第一笔落点。

### 3.2 笔刷行为

- 笔刷参数：大小、硬度、强度；默认软边、强度 100%。
- 同一笔内笔头重叠取最大值，再乘以笔强度并与蒙版合成：同笔内重叠与停留不继续累积；多笔之间正常累积。
- 采样按源半径的固定比例插值重采样，独立于鼠标事件密度：不同事件密度得到同一笔画。
- 蒙版合成公式（组合初值 M=0）：
  - 增加：`M' = M + (1 − M) * a`
  - 减去：`M' = M * (1 − a)`
  - 其中 `a` 为该组成项的覆盖率。
- 顺序固定：先按组成项顺序合成完整蒙版，再对完整蒙版羽化，最后整体反相；不能逐组成项羽化来代替整体羽化。
- 源透明区域在蒙版中保持透明（不产生覆盖率）。

### 3.3 快捷键与手势

- `Alt` 临时擦除；`Space` 临时平移；`[` `]` 调整笔刷大小；`O` 覆盖显示。
- 文本输入状态（如重命名层）不触发上述画布快捷键。
- 按下时冻结笔刷参数：笔画进行中若发生缩放或几何改变，必须先结束当前笔画再执行该操作。
- `Space` 按住时先提交有效笔画再平移，松开后下一次按下开始新笔，避免跨越平移连成一条线。
- `Alt` 可在按下时确定本笔是增加还是减去；同一条历史记录中不允许混用增减操作。

### 3.4 历史与提交

- 一笔 / 一次渐变拖动 / 一次参数拖动 = 一条历史项。
- `Esc` 取消未提交的操作。
- 切图、切层、切工具、窗口失焦时提交有效笔画（有实际效果的笔画）。

## 4. 数据与坐标、颜色不变量

### 4.1 文档模型

- Recipe 继续作为全局参数载体，语义不变。
- 新的 PhotoDocument / DocumentSnapshot 包含：AssetIdentity、全局 Recipe、有序 LocalAdjustmentLayer 列表、revision。
- 局部层：稳定 ID、名称、enabled/opacity、九个参数、mask 组成项。
- mask 组成项：笔触/渐变稳定 ID、源坐标几何、强度、操作（增加/减去）；mask 的 feather/invert 持久化。
- 选择态、覆盖显示、当前工具状态属于临时 view，不持久化为效果，不写入 Recipe。
- 扩展 EditHistory 为不可变小快照共享，保留跨图统一时间线；Undo/Redo 单调递增 revision；禁止整图 RGBA 历史复制。
- 旧 Recipe 与预设保持全局语义：不能把局部蒙版误带到其他照片。
- 功能切片新增的接口需先核查现有实际入口（见 [S3-LOCAL-EDITING-PLAN.md](S3-LOCAL-EDITING-PLAN.md) 的任务表）；本节只给建议接口职责与最小字段，不编造现成已实现 API。

### 4.2 源坐标

- 源为方向归一化后的原图像素中心；半径同样以原图像素为单位。
- 交互链：DIP → 画布输出像素 → 共享 `outputToSource` → 绿色参考的完整源；该链路包含 crop/angle/flip/perspective/distortion。
- 色差通道不分别锚定蒙版：蒙版只按绿色参考坐标定位；源半径不是 DIP，也不是屏幕物理像素。
- 非线性回源需处理无效映射与透明边界；X/Y 实际支持尺度分别参与换算（不是单一各向同性比例）。
- 预览与全源重放使用同一份记录。
- 渐变控制点跟随源内容；几何改变后蒙版仍需贴合源内容。

### 4.3 渲染顺序与算子

- 总体顺序：既有 源 WB/镜头暗角/几何与通道校正/去边色/空间准备/全局光色 → 局部层（自下而上）→ 全局裁后暗角/颗粒 → 既有显示或输出分支。
- 既有源阶段的相对顺序按 [COLOR-CONTRACT.md](COLOR-CONTRACT.md) 与实际代码保留；本文的简述不得用来重排既有阶段。
- 局部算子在 straight linear Rec.2020 float32 上工作：RGB 暖冷，再曝光/对比/分区影调/饱和度，沿对应现有算法；仅这九个字段参与。
- 每层对下方结果 F 计算 A(F)，合成：`C = F + (mask * opacity) * (A(F) − F)`；alpha 不变；不提前裁剪负值/HDR。
- 局部曝光用 `RGB * 2^EV`。
- 局部饱和度沿既有 Rec.2020 亮度定义。
- 每层只按上式混合一次；局部算子 A 不再内部混合蒙版。不同局部层仍各自按其蒙版顺序生效。
- 没有局部层时保持原输出基线与原快路径；无局部层的照片不得因为新代码而改变路径或像素。
- 任何新 RAW/缓存路径必须携带：cameraToWork、draftBalance、rawWB、actualXYscale、曲线切线、全局字段与算法身份；不得重复烘焙已准备的几何/WB。

### 4.4 任务门禁与取消

- RenderSnapshot 完整冻结（不可变）。
- EditTag 在现有 session/revision/draft/job/geometry 之外增加 local identity 与 view epoch。
- 三处门禁：入队、显示、提交。
- cancel 先使结果失效，再协作结束在途任务；不能释放仍被他人持有的缓冲。
- 笔刷可用性由实际就绪能力检查决定，不能用显示缩略图就绪来猜测。
- 覆盖色显示不进入普通预览、直方图或缓存输出数据。

## 5. 分块、缓存与资源

- 分块：初始 256px 逻辑 tile；局部缓存 256MiB。
- 512px 仅用于对照测试，默认不改。
- halo 按实际有限 support 加映射足迹计算；羽化跨块与跨原图边界必须统一。
- 全局空间算子先保持现有整图/条带正确路径，不要求一次重写成通用 tile 引擎。
- cache key 包含：asset hash、算法版本、全局 recipe、geometry、mip、target、完整坐标、local versions、tile。
- ready / inflight / pinned 分别统计；LRU 不得淘汰正在使用（被引用）的条目。
- 一个完整源或一个 RAW 在途。
- 512MiB 显示缓存与 4GiB 临时磁盘沿现有合同，不作为 RAM 预算。
- 稳态进程树私有提交 ≤ 1.5GiB、峰值 ≤ 2.5GiB 为**待测目标**；统计包含父子进程的源、prepared/spatial/output/mask/halo 与旧任务。当前新功能未实施、指标未验收，不能声称已达成，也不能据此断言已经超标。

## 6. 保存与恢复边界

- 保存单位为整个照片组：路径/hash/照片列表/标记/各图 recipe + 有序局部层；使用简化 SQLite、单 writer，引用原片，不内嵌源文件。
- 保存流程：冻结快照 → 一致临时目标 → 关闭/刷新 → 同卷原子替换；失败保留旧数据。
- 保存成功后新一轮编辑仍为 dirty；恢复工作副本不覆盖显式保存。
- 缺源可重定位；hash 变化不默默接受。
- 格式/算法版本未知时不能丢弃节点或覆盖原项目；重开保留编辑结果，Undo 从新会话开始。
- 停止编辑 2 秒后更新独立恢复副本，不覆盖显式保存。
- 本轮不做：完整 undo 持久化、通用去重、大型平台能力。
