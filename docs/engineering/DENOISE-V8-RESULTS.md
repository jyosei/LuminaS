# 传统亮度与色彩降噪

2026-10-13，LuminaS。Qt6.8.3/MSVC2022/LibRaw0.22.2 OpenMP4 PASSIVE/LCMS2.19.1，CPU float32生产路径；未新增AI或浏览器引擎。

## 实现与范围

细节卡片新增亮度降噪、色彩降噪各0–1，默认0；单项复位、独立recipe与一手势一Undo沿现有窗口。亮度Y和色差R−Y/B−Y分别作alpha归一自引导Gaussian近似统计，亮度源σ2px、色差σ4px，均按源采样尺度换算；组合保持色彩降噪不改Y，负值/超白不剪工作域，透明邻域不引入脏边。完整公式、eps与顺序见COLOR-CONTRACT。

4K缓存至多3张float差值，强度复用；新增未准备通道才重建，几何/源改变失效。完整源不缓存45MP稠密差值图，而用128行条带、双重滤波halo和原始尾行备份原位组合。4K初版也用128行，后改512行减少任务调度；结果仍取真实4K像素，未缩小预览。空间各基底共同从中性几何图估计，组合顺序为降噪→去雾→纹理/清晰度增益→锐化→全局光色→SDR，不宣称逐算子重新估计邻域或商业等价。

## 限制与后续

最终核心CTest3/3、0失败、131.34秒，S2为127.63秒，见`denoise-v8-ctest.log`。新增降噪/缓存/条带/反馈用例后S2已实际超过旧120秒总测试时限，因此仅S2超时设180秒；每段持续反馈≥4帧、数学精度/源安全门槛没有降低，S1保持120秒。此默认测试的私有真实图片用例仍跳过，真实RAW/JPEG由独立原生与probe覆盖。

传统平滑会损失低对比纹理；没有模型重建、相机ISO噪声标定、皮肤保护或商业质量等价。真实R7人像只覆盖工程/观察，仍需已知干净参考、更多ISO/肤色/暗部/细发样片及正式质量验收。不是原图100%预览，preview/full采样不交换；物理尺度一致不代表逐像素相等。

全部空间效果4K基底40bytes/像素，R7 375MiB、方形4K562.5MiB，另加至多约8MiB去雾系数；完整源条带避免新增3张45MP差值图。目标8GB机、真实45MP RAW、稳态进程树和正式p95/30/60FPS仍未认证。S2独立边缘蒙版、取色/预设/颗粒/光学/校准等缺口继续列于S2-COMPLETION-AUDIT，S3仍仅准备。
