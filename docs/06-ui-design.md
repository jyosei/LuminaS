# 工作区视觉设计 · 第二版

2026-10-12。根据反馈，替换第一版偏线框的界面。技术栈、轻量化预算和开发分期继续保留；本次只完善产品界面与原型。

## 参考与取舍

参考 [Photoshop 工作区说明](https://helpx.adobe.com/photoshop/desktop/get-started/learn-the-basics/workspace-overview.html) 中的应用栏、文档区、工具栏、上下文选项与分组面板；参考 [像素蛋糕官方产品介绍](https://www.pixcakeai.com/) 和 [使用手册](https://www.pixcakeai.com/guide/) 中调色、人像修饰、局部工具与批量工作流的分组。品牌图形和产品截图不作为 Lumina 的界面资产复用。

当前建议以“摄影精修”为默认工作区，以“图层合成”为高级工作区。轻量化通过按任务组织信息、折叠次要工具与控制数据开销实现；常用参数不能因为追求简单而难以找到。

## 视觉与布局

- 中性灰背景，亮度分成应用框架、属性面板、画布三层；随系统支持深浅两种主题。紫灰色只标记主要操作、当前工具与选中项，避免影响照片颜色判断。
- 桌面工具栏约 43 px；属性区默认 302 px，可在设计预览中调宽。顶部依次为菜单/项目栏和全局操作，画布内保留文档标签与上下文工具属性。
- 照片占中央区域，周围留适当的视觉缓冲。前后比较在全局操作区；选择人物、选择背景和蒙版显示位于画布附近。
- 右侧“调色 / 人像 / 局部”三组。基本参数使用紧凑滑杆配数值输入，单项可复位；曲线与 HSL 折叠，避免常用控件过度分散。
- 图层展示图片缩略图、调整类型、蒙版、显隐和选中态。摄影工作区默认折叠，合成工作区默认展开，并精简上方参数数量。
- 底部为同一照片的虚拟副本比较，不把同一个素材伪装为多张拍摄照片。原片、自然、暖调只是此原型的命名效果。
- 边界用细线而非大面积卡片；控件主要使用 3–5 px 圆角。产品名称与主要操作形成少量强调，正文和状态采用常规字重。

## 原型交互

可交互：风格切换、曝光/色彩近似预览、高光/阴影等近似反馈、数值输入、复位、撤销/重做、前后比较、手动工具切换、预设形状选区、蒙版显示/反选、候选接受/放弃、图层显隐、导出设置展示。

人物修饰、真实液化、RAW 解码、精确 AI 识别与生成未实现。人像参数仅显示数值/布局；蒙版由预设路径描绘，候选只叠加局部暖色。曲线图用于布局示意；直方图来自当前样片 RGB 预览像素。颜色反馈只是浏览器近似实现，不代表正式引擎的颜色算法。

重新检查深浅主题和约 1024 / 736 / 320 px 内容宽度，测试主要交互、脚本错误与横向溢出；逐张查看桌面截图。窄屏检查服务于对话预览，不代表首版将提供手机编辑器。
